## 测试建议

1. 启动应用
2. 点击雷达按钮 → 检查视图加载
3. 点击"添加信息源" → 检查弹窗
4. 添加 RSS 信息源（如 GitHub Trending RSS）
5. 点击"立即扫描" → 检查扫描功能
6. 点击搜索按钮 → 检查搜索视图
7. 输入搜索词 → 检查结果展示
8. 点击导入按钮 → 检查导入功能
9. 检查 toast 通知是否显示
