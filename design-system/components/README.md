# 组件库

本文档列出 OS-Compass 设计系统中的所有组件及其使用规范。

## 基础组件 (Base Components)

### Button

操作按钮，支持多种变体和状态。

**变体**：

| 变体 | 样式 | 使用场景 |
|------|------|----------|
| Primary | 蓝色背景 | 主要操作，如"保存"、"导入" |
| Secondary | 边框按钮 | 次要操作，如"取消"、"返回" |
| Ghost | 透明背景 | 低优先级操作 |
| Danger | 红色 | 危险操作，如"删除" |

**状态**：default / hover / active / disabled / loading

---

### Input

文本输入框，支持多种类型和状态。

**类型**：text / password / url / number

**状态**：default / focus / error / disabled

---

### Select

下拉选择器。

**状态**：default / open / disabled

---

### Dialog / Modal

模态对话框，用于重要操作确认或表单填写。

---

### Toast

轻提示，用于操作反馈。

| 类型 | 颜色 | 使用场景 |
|------|------|----------|
| Success | 绿色 | 复制成功、保存成功 |
| Error | 红色 | 操作失败 |
| Warning | 黄色 | 警告信息 |
| Info | 蓝色 | 提示信息 |

---

### Tabs

标签页切换，用于同一内容的不同视图。

---

## 业务组件 (Business Components)

### ProjectCard

项目卡片，出现在看板视图中。

**显示信息**：
- 语言图标
- 项目名称
- 来源平台（GitHub/Gitee/NPM/PyPI）
- 简介（最多2行）
- 分类标签

**状态**：default / hover (阴影加深) / dragging

---

### ProjectRow

项目行，出现在列表视图中。

**显示信息**：
- 复选框
- 语言图标 + 项目名称 + URL
- 分类路径
- Stars 数
- 语言
- 生命周期状态
- 更新时间
- 操作菜单

---

### CategoryTree

分类树形结构，用于分类管理页面。

**节点信息**：
- 展开/折叠图标
- 文件夹图标
- 分类名称
- 路径标识
- 项目数量
- 操作按钮（编辑/删除）

**交互**：
- 点击展开/折叠
- 右键菜单
- 拖拽排序
- 编辑分类详情

---

### CategorySelector

分类选择器，出现在列表视图顶部筛选区。

**特点**：
- 树状下拉结构
- 显示层级缩进
- 支持多选（可选）

---

### ImportForm

项目导入表单。

**字段**：
- 来源类型（GitHub/Gitee/NPM/PyPI/手动）
- URL / 包名
- 分类选择
- 自动 AI 分析开关

---

### AIReportPanel

AI 报告展示面板。

**内容**：
- 健康度评分（进度条）
- License 合规
- 安全提示
- 用户口碑

---

### RunbookPanel

场景化指导手册面板。

**内容**：
- 环境要求
- 安装步骤
- 运行命令
- 二开入口路径

---

### ReadmePanel

README 展示面板。

**功能**：
- 原文/翻译 Toggle
- Markdown 渲染

---

### ClonePanel

克隆操作面板，位于项目详情页的"克隆"标签页。

**功能**：
- 设置克隆目录（Path Picker）
- 配置克隆代理（协议/地址/端口/用户名/密码）
- 显示克隆命令（可复制）
- 执行克隆操作

**状态**：default / configuring / cloning / success / error

**交互**：
| 操作 | 说明 |
|------|------|
| 选择目录 | 打开系统文件选择对话框 |
| 保存设置 | 持久化到 settings 表 |
| 复制命令 | 复制 git clone 命令到剪贴板 |
| 执行克隆 | 程序自动执行 git clone |

---

### NotesPanel

本地笔记面板。

**功能**：
- 笔记列表
- 添加/编辑笔记
- 时间戳显示

---

### UserInfoPanel（数据保险箱）

用户自定义信息管理面板。

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| key | 文本 | 键名 |
| value | 文本/加密 | 值 |
| is_secret | 布尔 | 敏感标识 |

**操作**：
| 操作 | 说明 |
|------|------|
| 复制 | 点击复制值到剪贴板 |
| 编辑 | 修改键值 |
| 删除 | 移除条目 |

**敏感信息显示**：
- 敏感字段显示 `••••••`
- 复制时自动解密

---

### SettingsTabs

设置中心标签页导航。

**标签**：
- 通用
- 下载
- LLM（大模型）

---

### SettingsForm

设置表单组件。

**通用设置**：
- 数据目录（Path Picker）
- 主题选择
- 语言选择

**下载设置**：
- 源码目录（Path Picker）
- 编辑器选择
- 代理配置

**LLM 设置**：
- 供应商选择
- API Base URL
- API Key（加密显示）
- 模型名称
- 测试连接按钮

---

### ProxyForm

代理配置表单。

**字段**：
- 启用开关
- 协议选择（HTTP/HTTPS/SOCKS5）
- 地址
- 认证（用户名/密码）
- 仅 Git Clone 代理

---

### LLMConfigForm

大模型配置表单。

**字段**：
- 供应商下拉
- API Base URL
- API Key（密码框 + 显示切换）
- 模型名称
- 测试连接按钮

---

### StatusBadge

生命周期状态徽章。

| 状态 | 样式 |
|------|------|
| 待探索 | 蓝色背景 |
| 研究中 | 黄色背景 |
| 已落地 | 绿色背景 |
| 弃用 | 灰色背景 |

---

### EmptyState

空状态展示。

**组成**：
- 空状态图标
- 说明文字
- 操作按钮

---

### ContextMenu

右键上下文菜单。

**触发**：右键点击目标元素

---

## 组件状态规范

| 状态 | 视觉表现 |
|------|----------|
| Default | 正常显示 |
| Hover | 颜色加深 / 阴影加深 |
| Active | 按下效果 |
| Disabled | opacity-50，禁用交互 |
| Loading | 显示加载动画 |
| Error | 红色边框 |
| Selected | 背景高亮 |

---

## 贡献新组件

如需新增组件，请遵循以下规范：

1. 在本文档中添加组件说明
2. 包含：用途、变体/类型、状态、代码示例
3. 在对应页面原型中实现示例
4. 保持与现有组件风格一致
