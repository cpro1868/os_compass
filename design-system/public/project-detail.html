项目简介

React 是一个用于构建用户界面的 JavaScript 库。它由 Facebook 开发和维护，采用组件化开发模式，通过虚拟 DOM 提高渲染性能。React 广泛应用于单页应用、移动应用和服务器端渲染场景。

中大型 Web 应用 需要高度交互的 UI 移动端跨平台开发

场景化指导手册

1 环境要求

  • Node.js >= 18.0.0
  • npm >= 9.0.0 或 yarn >= 1.22.0

2 安装步骤

npm install react react-dom

或使用 Create React App

npx create-react-app my-app

3 运行项目

npm start

4 二次开发入口

src/ - 源代码目录

src/components/ - 组件目录

src/App.js - 主应用入口
