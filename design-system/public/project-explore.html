如何本地部署和运行？

根据 README 和 Runbook，React 本身是一个库而非完整应用，本地运行通常是运行它的示例或基于它创建项目：

1. 创建一个新项目（推荐方式）

npx create-react-app my-app
cd my-app
npm start

2. 运行 React 源码仓库（适用于贡献代码）：克隆仓库后执行 yarn install 安装依赖，再运行 yarn build 构建。

详细的环境要求（Node 版本等）在你的 Runbook 中已有记录，可以直接照做。
