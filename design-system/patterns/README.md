# 页面模式

本文档定义 OS-Compass 的常见页面级交互模式。

## 1. 主从布局 (Master-Detail) - 核心布局

### 1.1 布局结构

```
┌────────────────────────────────────────────────────┐
│                    左侧功能栏 (64px)                 │
│  ┌──────┐                                          │
│  │ Logo │  ← 应用 Logo                            │
│  └──────┘                                          │
│  ┌──────┐                                          │
│  │ 导入 │  ← 核心操作按钮                          │
│  │ 搜索 │                                          │
│  └──────┘                                          │
│  ┌──────┐                                          │
│  │ 看板 │  ← 视图切换                             │
│  │ 列表 │                                          │
│  └──────┘                                          │
│  ┌──────┐                                          │
│  │ 分类 │  ← 分类管理入口                          │
│  └──────┘                                          │
│  ┌──────┐                                          │
│  │ 设置 │  ← 底部设置入口                          │
│  │ 插件 │                                          │
│  └──────┘                                          │
├────────────────────────────────────────────────────┤
│                    主内容区                          │
│  ┌────────────────────────────────────────────┐    │
│  │  顶部栏（标题、操作按钮）                    │    │
│  ├────────────────────────────────────────────┤    │
│  │  内容区（列表/看板/详情等）                  │    │
│  │                                            │    │
│  └────────────────────────────────────────────┘    │
└────────────────────────────────────────────────────┘
```

### 1.2 左侧功能栏规范

| 区域 | 功能 | 说明 |
|------|------|------|
| Logo | 应用标识 | 固定，不可点击 |
| 核心操作 | 导入、搜索 | 一级操作入口 |
| 视图切换 | 看板、列表 | 切换主视图模式 |
| 分类管理 | 分类树入口 | 独立页面 |
| 底部设置 | 设置、插件 | 系统配置入口 |

**尺寸规范**：
- 宽度：64px (w-16)
- 图标尺寸：24px
- 文字标签：10px
- 按钮高度：48px (h-12)

## 2. 看板视图 (Kanban)

用于项目状态流转的视图模式。

**结构**：

```
┌────────────┬────────────┬────────────┬────────────┐
│  💡 待探索  │  🔬 研究中  │  ✅ 已落地  │  🗑️ 弃用   │
│     (3)    │     (2)    │     (5)    │     (1)    │
├────────────┼────────────┼────────────┼────────────┤
│ ┌────────┐ │ ┌────────┐ │            │            │
│ │ 项目1  │ │ │ 项目3  │ │            │            │
│ └────────┘ │ └────────┘ │            │            │
│ ┌────────┐ │            │            │            │
│ │ 项目2  │ │            │            │            │
│ └────────┘ │            │            │            │
└────────────┴────────────┴────────────┴────────────┘
```

**特点**：
- 看板视图**不需要**分类筛选
- 卡片支持拖拽跨列流转
- 每列显示项目数量

**状态枚举**：
| 状态 | 标识 | 说明 |
|------|------|------|
| TO_EXPLORE | 💡 待探索 | 新发现或感兴趣的项目 |
| DIVING | 🔬 研究中 | 正在评估的项目 |
| IN_USE | ✅ 已落地 | 已采用并使用的项目 |
| ABANDONED | 🗑️ 弃用 | 已放弃或避坑的项目 |

## 3. 列表视图 (List)

紧凑型数据展示，适合大量数据浏览和精确筛选。

**结构**：

```
┌─────────────────────────────────────────────────────────────┐
│  全部项目                              [搜索框] [分类▼] [标签▼] │
├─────────────────────────────────────────────────────────────┤
│ ☐ 项目名称      │ 分类        │ Stars │ 语言  │ 状态  │ 操作 │
├─────────────────────────────────────────────────────────────┤
│ ☐ facebook/react │ 前端框架   │ 220k  │ TS    │ 已落地│ ... │
│ ☐ vuejs/core    │ 前端框架   │ 45k   │ TS    │ 研究中│ ... │
└─────────────────────────────────────────────────────────────┘
```

**特点**：
- **需要**分类筛选（树状下拉）
- 支持多条件组合筛选
- 支持横向滚动

## 4. 详情页 (Detail)

用于查看单个项目的完整信息。

**结构**：

```
┌─────────────────────────────────────────────────────┐
│ [←返回]  [项目图标] facebook/react                 │
│          https://github.com/facebook/react   [编辑] │
├─────────────────────────────────────────────────────┤
│ [概览] [AI报告] [Runbook] [README] [克隆] [笔记] [🔒用户信息] │
├─────────────────────────────────────────────────────┤
│                                                     │
│  标签页内容区域                                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**标签页内容**：
| 标签 | 内容概要 |
|------|----------|
| 概览 | 基本信息、元数据、快速操作 |
| AI 报告 | 健康度评分、安全性、活跃度分析 |
| Runbook | 环境要求、安装/运行步骤、二开入口 |
| README | 双语对照（原文/翻译 Toggle） |
| 克隆 | 源码克隆设置与操作 |
| 本地笔记 | 用户自由编写的踩坑记录 |
| 用户信息 | **数据保险箱**（敏感凭证管理，加密存储） |

### 4.1 克隆标签页设计

**设计原则**：
- 克隆设置持久化（保存到系统设置）
- 克隆操作是一次性的，不记录"已克隆"状态
- 代理配置复用系统下载代理设置

**页面结构**：

```
┌─────────────────────────────────────────────────────────┐
│  克隆设置（持久化）                                      │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 克隆目录：[/path/to/workspace    ] [选择]         │  │
│  │ 代理：继承系统下载代理设置              [修改]     │  │
│  │                              [💾 保存设置]         │  │
│  └───────────────────────────────────────────────────┘  │
│                                                         │
│  克隆操作（一次性执行）                                  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ git clone https://github.com/facebook/react       │  │
│  │                                                   │  │
│  │  [复制命令]                    [🚀 执行克隆]      │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

**数据存储**：
| 字段 | 存储位置 | 说明 |
|------|----------|------|
| clone_path | settings 表 | 全局克隆目录，所有项目共用 |
| clone_proxy_* | settings 表 | 克隆专用代理配置 |

**交互说明**：
- 选择目录：调用系统文件选择对话框
- 保存设置：保存到 settings 表，下次打开自动加载
- 复制命令：将 git clone 命令复制到剪贴板
- 执行克隆：程序自动执行 git clone（使用已保存的目录和代理）

## 5. 分类管理页面

独立的分类管理页面，支持多层级树形结构。

**结构**：

```
┌─────────────────────────────────────────────────────────────┐
│ [←返回]  分类管理                               [+新建分类] │
├─────────────────────────────────────────────────────────────┤
│ ┌─ 前端框架 (frontend-framework) ──────────────── [3项] ─┐│
│ │  ├─ React 生态 ────────────────────────────── [2项] ─┐ ││
│ │  │  └─ React 核心库 ──────────────────────── [1项] ─┐│ ││
│ │  │                                                  ││ ││
│ │  └─ Vue 生态 ──────────────────────────────────── [1项] ││
│ │                                                        │
│ ├─ 后端服务 ─────────────────────────────────────── [3项] ││
│ └─ 数据库 ───────────────────────────────────────── [2项] ││
└─────────────────────────────────────────────────────────────┘

┌─ 编辑分类：React 生态 ────────────────────────────────────┐
│  分类名称: [React 生态          ]  路径: [react-ecosystem]│
│  上级分类: [前端框架 ▼]                                    │
│  分类说明:                                                │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ React 生态是指与 React 核心库相关的项目...          │  │
│  │ - React 官方库及周边                                │  │
│  │ - React 应用框架                                    │  │
│  └─────────────────────────────────────────────────────┘  │
│                                    [取消]  [保存]         │
└─────────────────────────────────────────────────────────────┘
```

**分类字段**：
| 字段 | 说明 | 用途 |
|------|------|------|
| name | 分类名称 | 显示名称 |
| path | 路径标识 | 系统标识，建议英文 |
| explain | 分类说明 | **供 AI 理解，用于精准归类** |
| sort_order | 排序权重 | UI 排序 |
| parent_id | 上级分类 | 构建层级关系 |

## 6. 设置中心页面

多标签页配置界面。

**标签页**：
| 标签 | 内容 |
|------|------|
| 通用 | 数据目录、主题、语言 |
| 下载 | 源码目录、编辑器、代理设置 |

## 7. 拖拽交互 (Drag & Drop)

### 看板流转
- 整个卡片可拖拽
- 进入目标列时高亮占位
- 释放后即时保存状态

### 分类树
- 支持跨层级拖拽
- 拖拽时显示插入位置指示线
- 释放后更新层级关系

## 10. 右键菜单 (Context Menu)

用于单项操作的快捷菜单。

**分类节点右键菜单**：
- 新建子分类
- 重命名
- 添加说明
- 删除

## 11. Toast 提示

操作反馈的轻提示。

| 类型 | 颜色 | 场景 |
|------|------|------|
| Success | 绿色 | 复制成功、保存成功 |
| Error | 红色 | 操作失败、连接失败 |
| Warning | 黄色 | 警告信息 |
| Info | 蓝色 | 提示信息 |
