# 设计系统使用文档

## 1. 快速开始

### 查看原型

直接在浏览器中打开 `public/` 目录下的 HTML 文件即可预览：

```bash
# macOS
open public/index.html

# Windows
start public/index.html
```

### 推荐工作流

1. **设计阶段**：使用 HTML 原型快速验证布局和交互
2. **开发阶段**：参考 `tokens/` 和 `components/` 文档确保实现一致
3. **验收阶段**：对比原型与实现，确保视觉还原

## 2. 设计令牌 (tokens/)

设计令牌是设计系统的基础原子，包含：

| 类型 | 说明 | 示例 |
|------|------|------|
| 颜色 | 主色、辅助色、语义色 | `blue-600`、`green-500` |
| 字体 | 字体族、字号、字重 | `Inter`、14px、medium |
| 间距 | 间距层级 | 4px、8px、16px、24px |
| 圆角 | 组件圆角层级 | 4px、8px、12px |
| 阴影 | 卡片阴影层级 | sm、md、lg |

详见 `tokens/README.md`

## 3. 组件规范 (components/)

### 基础组件

| 组件 | 用途 | 状态 |
|------|------|------|
| Button | 操作按钮 | default, hover, active, disabled |
| Input | 文本输入 | default, focus, error, disabled |
| Select | 下拉选择 | default, open, disabled |
| Dialog | 模态对话框 | - |
| Toast | 轻提示 | success, error, warning, info |
| Card | 卡片容器 | - |
| Tabs | 标签页切换 | - |

### 业务组件

| 组件 | 用途 | 对应页面 |
|------|------|----------|
| ProjectCard | 项目卡片 | main-interface.html |
| CategoryTree | 分类树 | main-interface.html, category-manager.html |
| ImportForm | 导入表单 | import-form.html |
| AIReportPanel | AI 报告面板 | project-detail.html |
| SettingsForm | 设置表单 | settings.html |
| UserInfoPanel | 用户信息管理 | project-detail.html |
| PluginCard | 插件卡片 | plugin-manager.html |

详见 `components/README.md`

## 4. 页面模式 (patterns/)

常见页面级模式：

| 模式 | 说明 | 适用页面 |
|------|------|----------|
| 主从布局 | 侧边栏 + 主内容区 | 所有页面 |
| 看板视图 | 多列拖拽布局 | main-interface.html |
| 表单页 | 数据录入页面 | import-form.html, settings.html |
| 详情页 | 多标签内容展示 | project-detail.html |

详见 `patterns/README.md`

## 5. 常见问题

**Q: 为什么原型用 Tailwind CDN？**
A: 原型阶段使用 CDN 便于快速预览。实际项目应通过 npm 安装并定制配置。

**Q: 图标从哪里来？**
A: 使用 Font Awesome 6 Free 版本，通过 CDN 引入。

**Q: 如何贡献新组件？**
A: 在 `components/` 下创建文档说明，附上使用示例和状态定义。
