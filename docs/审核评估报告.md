## 八、爬虫服务评估

### 8.1 评估对象

| 项目 | 说明 |
|------|------|
| 项目路径 | `crawler/webtomd/` |
| 语言 | Go |
| 定位 | 将网页文章转换为离线 Markdown 笔记 |
| 架构 | CLI 工具 + 模块化 pkg |

### 8.2 技术栈

| 组件 | 库 | 说明 |
|------|------|------|
| CLI 框架 | cobra | 命令行参数解析 |
| HTML 解析 | goquery | DOM 操作 |
| 正文提取 | go-readability | 类似浏览器 Reader Mode |
| HTML→MD | html-to-markdown | 通用转换 |
| 浏览器渲染 | chromedp | Chrome DevTools Protocol |

### 8.3 核心能力

| 模块 | 功能 | OS-Compass 需求 |
|------|------|----------------|
| `pkg/fetcher` | 网页抓取（HTTP → API → 浏览器） | ✅ 可用 |
| `pkg/parser` | 正文解析 + 资源提取 | ✅ 可用 |
| `pkg/converter` | HTML → Markdown | ✅ 可用 |
| `pkg/downloader` | 图片/视频下载 | ⚠️ 可选保留 |
| `pkg/siteconfig` | 站点配置文件 | ✅ 可扩展 |

### 8.4 集成方案

**推荐：作为独立 HTTP 服务**

```
OS-Compass (Rust) → HTTP 请求 → web2md API → 返回 Markdown
```

**API 设计**：
```bash
# 启动服务
web2md serve --port 8080

# 调用接口
POST /crawl
Body: {"url": "https://example.com/project"}

# 返回
{
  "title": "Example Project",
  "markdown": "# Example Project\n\n...",
  "source": "fetch|api|browser"
}
```

### 8.5 改造任务

| 优先级 | 改造项 | 说明 |
|--------|--------|------|
| **P1** | 新增 HTTP API 服务 | 在现有 CLI 基础上新增 `web2md serve` 命令 |
| **P1** | 配置化端口和地址 | 从环境变量/配置文件读取 |
| **P1** | 保留现有所有功能 | 不删除微博/微信支持，做加法 |

**改造原则**：只新增 HTTP API，不删除现有 CLI 功能。

### 8.6 API 设计

```bash
# 启动服务
web2md serve --port 8080

# 调用接口
POST /crawl
Content-Type: application/json
Body: {"url": "https://example.com/project"}

# 返回
{
  "title": "Example Project",
  "markdown": "# Example Project\n\n...",
  "source": "http|api|browser",
  "fetched_at": "2026-06-28T17:00:00Z"
}
```

### 8.7 结论

✅ **web2md 完全可以作为 OS-Compass 的爬虫服务**。

✅ **LLM 配置：使用者自由配置**，支持 OpenAI/DeepSeek/Ollama 等。

✅ **GitHub/Gitee：双轨制**，有 Token 用 API，无 Token 用爬虫。
