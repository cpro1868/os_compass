### 6.4 编译环境配置

> ✅ **已解决**：2026-06-29

**解决方案**：创建 `.cargo/config.toml` 指定 MSYS2 MinGW 链接器

**配置文件**：`os-compass/src-tauri/.cargo/config.toml`
```toml
[target.x86_64-pc-windows-gnu]
linker = "D:\\Soft\\msys64\\mingw64\\bin\\gcc.exe"
ar = "D:\\Soft\\msys64\\mingw64\\bin\\ar.exe"
```

**编译命令**：
```cmd
set PATH=D:\Soft\msys64\mingw64\bin;D:\Soft\msys64\ucrt64\bin;D:\Soft\msys64\usr\bin;%PATH%
cd os-compass
pnpm tauri build
```

**验证结果**：
| 输出 | 路径 |
|------|------|
| exe | `src-tauri/target/release/os-compass.exe` (19MB) |
| MSI | `src-tauri/target/release/bundle/msi/os-compass_0.1.0_x64_en-US.msi` |
| NSIS | `src-tauri/target/release/bundle/nsis/os-compass_0.1.0_x64-setup.exe` |

**状态**：✅ 编译成功

### 6.5 编译环境问题

> ✅ **已解决**：2026-06-29

**问题**：ordinal 链接错误
```
error: export ordinal too large: 116185
```

**根因**：Rust GNU 工具链的 sysroot 指向错误的 MinGW 库路径

**解决方案**：配置 `.cargo/config.toml` 指定正确的 MSYS2 MinGW 链接器
