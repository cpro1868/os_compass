# M22: 意图搜索历史记录功能

> **创建时间**：2026-08-14
> **状态**：需求设计
> **优先级**：P1

---

## 1 概述

### 1.1 问题背景

SearchView 右上角侧边栏有"搜索历史"UI，但功能未实现。用户搜索后没有保存记录，历史列表为空，无法查看和复用历史搜索。

### 1.2 目标

实现意图搜索历史记录功能：
- 搜索完成后保存 query 到数据库
- 侧边栏展示历史记录列表
- 点击历史记录可重新加载搜索

### 1.3 存储位置

**系统库**（`plugins.db`）

**原因**：搜索历史是用户行为记录，与具体仓库无关，方便跨仓库使用。

---

## 2 数据模型

### 2.1 系统库表结构

```sql
CREATE TABLE IF NOT EXISTS search_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    query TEXT NOT NULL,
    result_count INTEGER DEFAULT 0,
    created_at TEXT DEFAULT (datetime('now', 'localtime'))
);

CREATE INDEX IF NOT EXISTS idx_search_history_created ON search_history(created_at DESC);
```

### 2.2 TypeScript 接口

```typescript
interface SearchHistoryItem {
  id: number;
  query: string;
  result_count: number;
  created_at: string;
}
```

---

## 3 功能设计

### 3.1 保存搜索记录

**触发时机**：每次意图搜索完成后

**存储内容**：
| 字段 | 值 |
|------|-----|
| query | 用户输入的搜索词 |
| result_count | 返回结果数量 |
| created_at | 当前时间 |

**SQL**：
```sql
INSERT INTO search_history (query, result_count) VALUES (?, ?)
```

### 3.2 展示历史列表

**UI 位置**：SearchView 右侧边栏"搜索历史"区域

**展示规则**：
- 按 created_at DESC 排序
- 限制最新 20 条
- 显示 query 文本（截断过长内容）

**空状态**：
- 图标：💬（灰色）
- 文案：暂无搜索记录
- 提示：开始搜索后会自动保存

### 3.3 点击重新搜索

**交互流程**：
1. 用户点击历史记录项
2. 将 query 填充到输入框
3. 自动触发搜索

### 3.4 清除历史（可选）

**交互**：点击侧边栏"清除"按钮

**SQL**：
```sql
DELETE FROM search_history
```
