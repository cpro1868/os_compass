# 扩展配置规范 (Extension Specification)

## 1. 概述

OS-Compass 采用**扩展化架构**实现多平台支持。每个平台（如 GitHub、Gitee）对应一个扩展，扩展负责：
- 识别平台 URL
- 获取项目信息
- 计算平台特有指标
- 质量评分（可选）

> **命名规范**：本期 MVP 的平台集成功能称为「扩展配置」，二期的高级功能（插件市场、热加载等）称为「插件系统」。

## 2. 扩展类型

### 2.1 源码来源扩展 (SourcePlugin)

用于从不同平台获取开源项目信息。

| 扩展 | ID | 类名 |
|------|-----|------|
| GitHub | `github` | `plugins::GitHubPlugin` |
| Gitee | `gitee` | `plugins::GiteePlugin` |
| 通用爬虫 | `crawler` | `plugins::CrawlerPlugin` |

## 3. 插件接口定义

### 3.1 Rust 实现

```rust
use async_trait::async_trait;
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

/// 扩展元信息
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PluginMeta {
    /// 扩展唯一标识符
    pub id: String,
    /// 显示名称
    pub name: String,
    /// 扩展实现类（模块路径）
    pub plugin_class: String,
    /// 版本号
    pub version: String,
    /// 插件描述
    pub description: String,
    /// 是否启用
    pub enabled: bool,
    /// 需要的系统变量声明
    pub required_variables: Vec<VariableDef>,
}

/// 变量定义
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VariableDef {
    /// 变量键名
    pub key: String,
    /// 显示名称
    pub name: String,
    /// 描述
    pub description: Option<String>,
    /// 是否敏感（加密存储）
    pub secret: bool,
    /// 默认值（可选）
    pub default: Option<String>,
}

/// 项目信息
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ProjectInfo {
    /// 平台标识
    pub platform: String,
    /// 原始 URL
    pub url: String,
    /// 项目名称
    pub name: String,
    /// 项目描述
    pub description: Option<String>,
    /// 编程语言
    pub language: Option<String>,
    /// 编程语言列表（JSON 数组）
    pub languages: Option<Vec<String>>,
    /// 许可证
    pub license: Option<String>,
    /// Git 地址
    pub git_url: Option<String>,
    /// Stars 数量
    pub stars: Option<i64>,
    /// Forks 数量
    pub forks: Option<i64>,
    /// Watchers 数量
    pub watchers: Option<i64>,
    /// Issues 数量
    pub open_issues: Option<i64>,
    /// 最后更新时间
    pub updated_at: Option<String>,
    /// 贡献者数量
    pub contributors: Option<i64>,
    /// README 内容
    pub readme: Option<String>,
    /// 平台特有数据（JSON）
    pub platform_data: Option<HashMap<String, serde_json::Value>>,
    /// 平台评分（插件计算）
    pub platform_score: Option<f64>,
    /// 数据质量标记
    pub quality: DataQuality,
}

/// 数据质量
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum DataQuality {
    /// 高质量：通过 API 获取，有完整数据
    High,
    /// 低质量：通过爬虫获取，数据不完整
    Low,
}

/// 插件错误
#[derive(Debug, thiserror::Error)]
pub enum PluginError {
    #[error("插件未启用")]
    Disabled,
    #[error("缺少必需变量: {0}")]
    MissingVariable(String),
    #[error("不支持的 URL: {0}")]
    UnsupportedUrl(String),
    #[error("网络请求失败: {0}")]
    NetworkError(String),
    #[error("API 错误: {0}")]
    ApiError(String),
    #[error("解析错误: {0}")]
    ParseError(String),
}

/// 平台特有指标
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PlatformMetrics {
    /// 平台名称
    pub platform: String,
    /// 原始评分（平台特有）
    pub raw_score: f64,
    /// 指标详情
    pub metrics: HashMap<String, MetricValue>,
}

/// 指标值
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(untagged)]
pub enum MetricValue {
    Number(f64),
    String(String),
    Boolean(bool),
}

/// 源码来源插件 trait
#[async_trait]
pub trait SourcePlugin: Send + Sync {
    /// 获取插件元信息
    fn meta(&self) -> PluginMeta;

    /// 检查是否匹配此插件
    fn matches(&self, url: &str) -> bool;

    /// 获取项目信息（优先使用 API，降级到爬虫）
    async fn fetch(&self, url: &str) -> Result<ProjectInfo, PluginError>;

    /// 获取平台特有指标
    async fn get_metrics(&self, url: &str) -> Result<PlatformMetrics, PluginError>;

    /// 获取系统变量
    fn get_variable(&self, key: &str) -> Option<String>;

    /// 设置变量读取器
    fn set_variable_provider<F>(&mut self, provider: F)
    where
        F: Fn(&str) -> Option<String> + Send + Sync + 'static;
}
```

## 4. 内置插件实现

### 4.1 GitHub 插件

```rust
// src-tauri/src/plugins/github.rs

pub struct GitHubPlugin {
    variable_provider: Box<dyn Fn(&str) -> Option<String> + Send + Sync>,
}

impl GitHubPlugin {
    pub fn new() -> Self {
        Self {
            variable_provider: Box::new(|_| None),
        }
    }
}

impl SourcePlugin for GitHubPlugin {
    fn meta(&self) -> PluginMeta {
        PluginMeta {
            id: "github".to_string(),
            name: "GitHub".to_string(),
            plugin_class: "plugins::GitHubPlugin".to_string(),
            version: "1.0.0".to_string(),
            description: "获取 GitHub 项目信息、健康度评分".to_string(),
            enabled: true,
            required_variables: vec![
                VariableDef {
                    key: "github_token".to_string(),
                    name: "GitHub Token".to_string(),
                    description: Some("GitHub Personal Access Token".to_string()),
                    secret: true,
                    default: None,
                },
                VariableDef {
                    key: "github_proxy".to_string(),
                    name: "代理地址".to_string(),
                    description: Some("HTTP 代理地址，如 http://127.0.0.1:7890".to_string()),
                    secret: false,
                    default: Some("".to_string()),
                },
            ],
        }
    }

    fn matches(&self, url: &str) -> bool {
        url.contains("github.com")
    }

    async fn fetch(&self, url: &str) -> Result<ProjectInfo, PluginError> {
        let token = (self.variable_provider)("github_token");

        if token.is_some() {
            self.fetch_with_api(url, token.unwrap()).await
        } else {
            self.fetch_with_crawler(url).await
        }
    }

    async fn get_metrics(&self, url: &str) -> Result<PlatformMetrics, PluginError> {
        // 获取原始数据后计算平台指标
        let info = self.fetch(url).await?;
        self.calculate_metrics(&info)
    }

    fn get_variable(&self, key: &str) -> Option<String> {
        (self.variable_provider)(key)
    }

    fn set_variable_provider<F>(&mut self, provider: F)
    where
        F: Fn(&str) -> Option<String> + Send + Sync + 'static,
    {
        self.variable_provider = Box::new(provider);
    }
}
```

### 4.3 通用爬虫扩展

```rust
// src-tauri/src/plugins/crawler.rs

pub struct CrawlerPlugin {
    crawler_url: String,
}

impl CrawlerPlugin {
    pub fn new(crawler_url: String) -> Self {
        Self { crawler_url }
    }
}

impl SourcePlugin for CrawlerPlugin {
    fn meta(&self) -> PluginMeta {
        PluginMeta {
            id: "crawler".to_string(),
            name: "通用爬虫".to_string(),
            plugin_class: "plugins::CrawlerPlugin".to_string(),
            version: "1.0.0".to_string(),
            description: "无 Token 时的降级方案，获取网页正文".to_string(),
            enabled: true,
            required_variables: vec![],
        }
    }

    fn matches(&self, url: &str) -> bool {
        // 匹配所有 URL，作为最后的降级方案
        true
    }

    async fn fetch(&self, url: &str) -> Result<ProjectInfo, PluginError> {
        // 调用 web2md HTTP 服务
        let markdown = self.crawl(url).await?;
        self.parse_markdown(url, &markdown)
    }

    async fn get_metrics(&self, _url: &str) -> Result<PlatformMetrics, PluginError> {
        // 爬虫无法获取指标
        Err(PluginError::ApiError(
            "爬虫模式不支持指标获取".to_string(),
        ))
    }

    fn get_variable(&self, _key: &str) -> Option<String> {
        None
    }

    fn set_variable_provider<F>(&mut self, _provider: F)
    where
        F: Fn(&str) -> Option<String> + Send + Sync + 'static,
    {
        // 爬虫插件不使用变量
    }
}
```

## 5. 插件管理器

```rust
// src-tauri/src/plugin_manager.rs

use std::collections::HashMap;
use std::sync::RwLock;

pub struct PluginManager {
    plugins: RwLock<HashMap<String, Box<dyn SourcePlugin>>>,
    variable_provider: Box<dyn Fn(&str) -> Option<String> + Send + Sync>,
}

impl PluginManager {
    pub fn new<F>(variable_provider: F) -> Self
    where
        F: Fn(&str) -> Option<String> + Send + Sync + 'static,
    {
        Self {
            plugins: RwLock::new(HashMap::new()),
            variable_provider: Box::new(variable_provider),
        }
    }

    /// 注册插件
    pub fn register<P: SourcePlugin + 'static>(&self, plugin: P) {
        let mut plugins = self.plugins.write().unwrap();
        let mut boxed = Box::new(plugin);
        boxed.set_variable_provider(self.variable_provider.as_ref().clone());
        plugins.insert(boxed.meta().id.clone(), boxed);
    }

    /// 获取插件列表
    pub fn list(&self) -> Vec<PluginMeta> {
        let plugins = self.plugins.read().unwrap();
        plugins.values().map(|p| p.meta()).collect()
    }

    /// 根据 URL 匹配插件
    pub fn match_plugin(&self, url: &str) -> Option<String> {
        let plugins = self.plugins.read().unwrap();
        for (id, plugin) in plugins.iter() {
            if plugin.matches(url) && plugin.meta().enabled {
                return Some(id.clone());
            }
        }
        None
    }

    /// 获取项目信息
    pub async fn fetch(&self, url: &str) -> Result<ProjectInfo, PluginError> {
        let plugin_id = self.match_plugin(url).ok_or_else(|| {
            PluginError::UnsupportedUrl(format!("没有插件支持此 URL: {}", url))
        })?;

        let plugins = self.plugins.read().unwrap();
        let plugin = plugins.get(&plugin_id).unwrap();
        plugin.fetch(url).await
    }
}
```

## 9. 插件注册流程

```
应用启动
    ↓
初始化 PluginManager
    ↓
从数据库加载插件列表（source_plugins 表）
    ↓
创建各插件实例
    ↓
设置变量读取器（从 system_variables 表读取）
    ↓
注册到 PluginManager
    ↓
完成
```
