## 测试用例

### 1. 分类管理

#### 1.1 分类树展示
- [ ] 进入「分类管理」页面
- [ ] 验证"未分类"系统分类显示
- [ ] 点击分类行，选中高亮（蓝色）
- [ ] 验证展开/折叠按钮可见（箭头图标）

#### 1.2 新建分类
- [ ] 点击「新建分类」按钮
- [ ] 验证上级分类默认选中刚才点击的分类
- [ ] 输入分类名称
- [ ] 保存后分类出现在列表中

#### 1.3 子分类
- [ ] 在分类行点击「+」按钮
- [ ] 验证自动填入上级分类
- [ ] 创建子分类成功

#### 1.4 编辑/删除
- [ ] 点击分类行的编辑按钮
- [ ] 修改名称后保存
- [ ] 验证修改生效
- [ ] 删除非系统分类成功
- [ ] 验证"未分类"不可作为上级分类
