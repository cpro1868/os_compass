## M22: 意图搜索历史记录

### 功能概述

SearchView 侧边栏"搜索历史"功能：搜索后保存 query → 展示历史列表 → 点击重新搜索。

### 详细任务

| Task | 内容 | 文件 | 工时 |
|------|------|------|------|
| Task 1 | system_db.rs 表 | 添加 search_history 表 | 0.5h |
| Task 2 | search_cmd.rs | get/clear_search_history 命令 | 1h |
| Task 3 | lib.rs | 注册命令 | 0.5h |
| Task 4 | search.ts | API 调用 | 0.5h |
| Task 5 | SearchView.tsx | 历史列表展示 | 1h |
| Task 6 | 点击重新搜索 | 填充 query 触发搜索 | 0.5h |
| Task 7 | 测试构建 | 全流程测试 | 1h |

### 数据模型

```sql
CREATE TABLE search_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    query TEXT NOT NULL,
    result_count INTEGER DEFAULT 0,
    created_at TEXT DEFAULT (datetime('now', 'localtime'))
);
```

### 存储位置

**系统库** `plugins.db`（跨仓库共享）

### 验收标准

| # | 标准 | 验证方法 |
|---|------|----------|
| 1 | 搜索后历史列表显示该记录 | 搜索 → 查看侧边栏 |
| 2 | 历史按时间倒序排列 | 多条记录查看顺序 |
| 3 | 点击历史记录重新搜索 | 点击 → 输入框填充 → 搜索触发 |
| 4 | 仓库切换后历史可用 | 切换仓库 → 查看历史 |
