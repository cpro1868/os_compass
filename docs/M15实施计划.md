# M15: 主页增强 实施计划

> **二期功能标记**：本计划所有功能均为二期（Phase 2）功能。
> **前置依赖**：M13（雷达/搜索）、M14（插件系统）可选

---

## 1 概述

### 1.1 目标

交付引导页/首页，提供极简入口体验，让用户快速开始使用。

### 1.2 核心价值

> **极简输入（消灭手动填表）**：界面上只有一个大大的输入框。用户只需要粘贴一个 GitHub 链接（或者你在网上看到的开源项目主页链接），敲击回车，用户的操作就结束了。

### 1.3 技术栈

- React 18 + TypeScript 5 + Tailwind CSS 3
- Tauri 2.0 + Rust

---

## 2 功能详情

### 2.1 首页/引导页

**功能**：用户首次使用或点击 Logo 时显示的主页。

| 功能点 | 说明 |
|--------|------|
| 极简输入框 | 大幅面居中输入框，粘贴 URL 自动识别平台 |
| 快速导入 | 输入即导入，无需多次点击 |
| 最近项目 | 下方显示最近导入的项目（最近 5 个） |
| 快捷入口 | 情报雷达、意图搜索入口（次要位置） |

### 2.2 极简输入框

**功能**：URL 自动识别 + 一键导入。

| 功能点 | 说明 |
|--------|------|
| 平台识别 | GitHub/Gitee/NPM/PyPI/GitLab/Docker Hub |
| 自动解析 | 识别后显示平台图标和项目名预览 |
| 回车导入 | 按 Enter 直接触发导入流程 |
| 错误处理 | 无效 URL 提示 + 手动录入入口 |

### 2.3 新手引导

**功能**：首次使用引导流程（可跳过）。

| 步骤 | 内容 |
|------|------|
| 1. 欢迎 | 介绍产品功能 |
| 2. 创建仓库 | 设置数据目录 |
| 3. 配置 LLM | API Key 设置 |
| 4. 导入项目 | 添加第一个开源项目 |
| 5. 完成 | 进入主界面 |

### 2.4 导航优化

**功能**：优化整体导航结构。

| 功能点 | 说明 |
|--------|------|
| Logo 点击 | 返回主页 |
| 侧边栏 | 简化，仅保留核心功能入口 |
| 面包屑 | 显示当前位置 |

### Task 2: 极简输入框组件

**Files:**
- New: `src/components/QuickImport.tsx`

**Step 1: 组件结构**

```tsx
interface QuickImportProps {
  onImport: (url: string) => void;
}

const QuickImport: React.FC<QuickImportProps> = ({ onImport }) => {
  const [url, setUrl] = useState('');
  const [status, setStatus] = useState<'idle' | 'loading' | 'success' | 'error'>('idle');
  const [preview, setPreview] = useState<ProjectPreview | null>(null);
  
  const handleSubmit = () => {
    if (validateUrl(url)) {
      onImport(url);
    }
  };
  
  return (
    <div className="quick-import">
      <Input 
        value={url}
        onChange={setUrl}
        onEnter={handleSubmit}
        placeholder={t('home.inputPlaceholder')}
        status={status}
      />
      {preview && <ProjectPreviewCard {...preview} />}
    </div>
  );
};
```
