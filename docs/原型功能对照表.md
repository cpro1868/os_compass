## 新增原型（仓库管理系统）

### 14. vault-manager.html - 仓库管理
- **状态**: ✅ 原型完成
- **功能**:
  - 仓库列表：卡片展示（名称、路径、项目数量、最后访问）
  - 当前仓库信息：显示名称、路径、项目数
  - 创建仓库：弹窗 + 4步进度显示
  - 导入已有仓库：弹窗 + 9步校验链展示（目录存在→db 存在→cryptokey 存在→db 可打开→12 表完整→关键列存在→密钥匹配→路径不重复→名称不重复），支持多种失败场景模拟（缺 db、缺 cryptokey、版本过旧、密钥不匹配、路径/名称重复）
  - 切换仓库：弹窗选择（底部含"导入已有仓库"和"创建新仓库"两个入口）
  - 删除仓库：确认弹窗（可选仅移除索引或彻底删除）
