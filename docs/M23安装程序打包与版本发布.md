## 2. 版本号管理策略

### 2.1 版本号规范

遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)：

```
主版本号.次版本号.修订号[-预发布标签]
  ↓          ↓      ↓         ↓
  MAJOR      MINOR    PATCH   PRE-RELEASE
  不兼容     向下兼容   修复bug  alpha/beta/rc
  重大变革   功能新增   小改动
```

### 2.2 版本升级规则

| 变更类型 | 升级位置 | 示例 |
|----------|----------|------|
| 破坏性变更 | MAJOR +1.0.0 | 数据库结构变更、API 不兼容 |
| 新功能 | MINOR +1 | 平台适配器、定时采集 |
| Bug 修复 | PATCH +1 | 向量搜索修复 |
| 预发布版本 | 0.1.0-alpha | 开发中测试版 |

### 2.3 版本号定义位置

| 位置 | 文件 | 字段 |
|------|------|------|
| Tauri 配置 | `tauri.conf.json` | `version` |
| Cargo 配置 | `src-tauri/Cargo.toml` | `package.version` |
| 应用内显示 | `src-tauri/src/lib.rs` | 常量或读取配置文件 |

### 2.4 版本同步机制

**问题**：版本号分散在多处，容易不一致

**解决方案**：
1. 以 `Cargo.toml` 为唯一数据源
2. 构建脚本自动同步到 `tauri.conf.json`
3. 使用 `tauri-build` 钩子自动更新

## 3. 打包配置

### 3.1 Tauri 打包配置

**文件**：`src-tauri/tauri.conf.json`

```json
{
  "productName": "OS-Compass",
  "version": "0.1.0",
  "identifier": "com.oscompass.app",
  "bundle": {
    "active": true,
    "targets": ["msi", "nsis"],
    "windows": {
      "certificateThumbprint": null,
      "digestAlgorithm": "sha256",
      "timestampUrl": ""
    },
    "publisher": "OS-Compass Team",
    "shortDescription": "开源项目全生命周期管理与决策系统",
    "longDescription": "OS-Compass 是一款基于本地优先理念设计的跨平台桌面端开源项目管理系统..."
  }
}
```

### 3.2 打包命令

```bash
# 完整打包
pnpm tauri build

# 仅 Windows
pnpm tauri build --target x86_64-pc-windows-msvc

# 指定版本号（通过环境变量）
VERSION=0.2.0 pnpm tauri build
```

### 3.3 打包产物位置

Tauri 原始构建产物：

```
os-compass/src-tauri/target/release/bundle/
├── msi/
│   └── os-compass_0.1.0_x64_en-US.msi
├── nsis/
│   └── os-compass_0.1.0_x64-setup.exe
└── appicons/
    └── ...
```

发布归档目录：

```
release/
├── os-compass_0.1.0_x64_en-US.msi
└── os-compass_0.1.0_x64-setup.exe
```

执行 `pnpm release:build` 后，MSI 与 NSIS 安装包会自动复制到项目根目录的 `release/`。

## 4. 发布流程

### 4.1 发布前检查清单

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | 版本号已更新 | Cargo.toml 和 tauri.conf.json 一致 |
| 2 | 构建成功 | `pnpm tauri build` 无错误 |
| 3 | 功能验证 | Previous 目录测试通过 |
| 4 | 测试用例通过 | `pnpm test` |
| 5 | 类型检查通过 | `pnpm typecheck` |
| 6 | 无敏感信息 | API Key 已移除 |
| 7 | CHANGELOG 更新 | 本次变更已记录 |

### 4.2 发布流程

```
┌─────────────────────────────────────────────────────────────┐
│                     发布流程                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1️⃣ 版本确认                                               │
│     ├── 检查 Cargo.toml 版本号                              │
│     └── 确认 CHANGELOG 已更新                              │
│                    ↓                                       │
│  2️⃣ 打包构建                                               │
│     ├── pnpm tauri build                                  │
│     └── 验证产物存在（MSI + NSIS）                         │
│                    ↓                                       │
│  3️⃣ 功能测试                                               │
│     ├── 运行 Previous/os-compass.exe                       │
│     └── 核心功能验证                                       │
│                    ↓                                       │
│  4️⃣ Git Commit & Tag                                      │
│     ├── git add .                                         │
│     ├── git commit -m "chore: bump version to v0.2.0"   │
│     └── git tag -a v0.2.0 -m "Release v0.2.0"          │
│                    ↓                                       │
│  5️⃣ GitHub Release                                        │
│     ├── git push && git push --tags                       │
│     └── GitHub Actions 自动创建 Release                    │
│                    ↓                                       │
│  6️⃣ 发布验证                                               │
│     ├── 下载安装包                                         │
│     └── 全新环境安装测试                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 GitHub Release 自动生成

**方式**：使用 GitHub Actions + `softprops/action-gh-release`

**.github/workflows/release.yml**：
```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          
      - name: Install pnpm
        run: npm install -g pnpm
        
      - name: Install deps
        run: pnpm install
        
      - name: Build
        run: pnpm tauri build
        
      - name: Release
        uses: softprops/action-gh-release@v1
        with:
          files: |
            src-tauri/target/release/bundle/msi/*.msi
            src-tauri/target/release/bundle/nsis/*.exe
          generate_release_notes: true
```

## 6. 自动更新（未来扩展）

### 6.1 Tauri Updater

Tauri 内置自动更新支持：

```json
{
  "plugins": {
    "updater": {
      "endpoints": [
        "https://releases.os-compass.app/{{target}}/{{arch}}/{{current_version}}"
      ],
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

### 6.2 更新流程

```
用户点击"检查更新"
      ↓
应用查询 update_endpoint
      ↓
比对当前版本 vs 最新版本
      ↓
有新版本 → 显示更新对话框
      ↓
用户确认 → 下载并安装
```

### 6.3 实施条件

| 条件 | 说明 |
|------|------|
| 公网部署 | 需要 CDN/静态文件托管 |
| HTTPS | 必须是 HTTPS |
| 签名验证 | 需要 Ed25519 公私钥对 |
| GitHub Release | 发布产物在 GitHub |

**当前阶段暂不实施**，待公网部署后实现。
