> **版本**：V1.0
> **日期**：2026-06-29
> **适用阶段**：Phase 0 完成后、Phase 1-1 MVP 发版前

## 1. 测试目标

本文档用于验证 OS-Compass 是否满足 MVP 核心功能目标：

1. **项目导入**：GitHub/Gitee/NPM/PyPI 平台 URL 自动识别和导入
2. **AI 分析**：健康度评分、AI 报告生成、README 翻译
3. **本地联动**：git clone 下载、IDE 打开
4. **数据安全**：敏感信息加密存储

## 6. API 契约测试

### 6.1 项目导入 API

```
POST /api/projects/import
{
  "url": "https://github.com/facebook/react",
  "auto_analyze": true,
  "auto_translate": true
}
```

**成功响应**：
```json
{
  "status": "success",
  "data": {
    "id": 1,
    "name": "react",
    "lifecycle_status": "TO_EXPLORE",
    "data_status": "ACTIVE",
    "health_score": 85
  }
}
```

**失败响应**：
```json
{
  "status": "error",
  "error": {
    "code": "INVALID_URL",
    "message": "URL 格式不正确"
  }
}
```

### 6.2 错误码基线

| 错误码 | 含义 |
|--------|------|
| `INVALID_URL` | URL 格式无效 |
| `PLUGIN_NOT_FOUND` | 不支持的平台 |
| `NETWORK_FAILED` | 网络请求失败 |
| `DUPLICATE_PROJECT` | 项目已存在 |
| `LLM_NOT_CONFIGURED` | 未配置 LLM |
| `LLM_API_ERROR` | LLM 调用失败 |
| `SYSTEM_CATEGORY` | 系统分类不可删除 |
| `HAS_CHILDREN` | 存在子分类 |

### 7.2 性能要求

| 指标 | 要求 |
|------|------|
