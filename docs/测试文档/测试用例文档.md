## 一、测试前准备

### 1.1 环境要求

| 项目 | 版本要求 | 检查命令 |
|------|----------|----------|
| Windows | 10+ | - |
| Node.js | 18+ | `node --version` |
| pnpm | 8+ | `pnpm --version` |
| Rust | 1.75+ | `rustc --version` |
| Git | 2.30+ | `git --version` |
| VS Code（可选） | 最新 | `code --version` |

### 1.2 测试账号准备

| 账号类型 | 必要性 | 准备方式 |
|----------|--------|----------|
| GitHub Token | 可选 | GitHub Settings → Developer settings → Personal access tokens |
| Gitee Token | 推荐 | Gitee 设置 → 私人令牌 |
| LLM API Key | **必须** | OpenAI / DeepSeek / Ollama |
| 代理 | 可选（国内必须） | HTTP/SOCKS5 代理 |

### 1.3 测试命令

```powershell
# 1. 克隆仓库
git clone <仓库地址> os-compass
cd os-compass

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm tauri dev

# 4. 运行测试
pnpm test
```
