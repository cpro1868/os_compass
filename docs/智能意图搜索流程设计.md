# 智能意图搜索流程设计

> 创建时间：2026-07-28
> 更新时间：2026-08-04
> 状态：**需求定版（ChatGPT 风格）**

---

## 1. 核心设计

### 1.1 设计理念

**像和 ChatGPT 聊天一样**：
- 对话式交互，自然亲切
- 追问可细化
- 结果以消息形式展示

### 1.2 流程图

```
用户输入 → 意图分析（LLM） → 本地搜索（项目卡片） → LLM 推荐（文字） → 对话展示
                     ↓
                 意图不明 → 追问确认
```

### 1.3 关键点

| 特性 | 说明 |
|------|------|
| 本地优先 | 本地有就直接返回项目卡片 |
| LLM 补充 | 本地不足时，LLM 用知识推荐（文字形式） |
| 主题限定 | 只回答开源项目相关问题 |
| 防白嫖 | 闲聊、无关话题引导到开源项目 |

## 2. Step 1：意图分析

### 2.1 Prompt

```
你是一个开源项目推荐助手。用户输入：「{user_input}」

你的职责是帮助用户找到合适的开源项目。注意：
1. 只回答开源项目相关的问题
2. 商业软件、不开源的直接拒绝或引导找开源替代品
3. 闲聊、无关话题引导到开源项目上来

请分析用户意图：
- 明确意图：用户想要找特定类型的开源项目
- 不明确意图：模糊描述、闲聊、无法直接搜索

返回格式（JSON）：
明确：{"intent": "clear", "keywords": ["关键词"]}
不明确：{"intent": "unclear", "questions": ["追问问题"], "options": ["选项A", "选项B"]}
```

### 2.2 返回结构

```typescript
interface IntentAnalysis {
  intent: 'clear' | 'unclear';
  keywords?: string[];     // 搜索关键词
  questions?: string[];    // 追问问题
  options?: string[];      // 选项
}
```

## 3. Step 2：追问确认

### 3.1 触发条件

`intent === 'unclear'` 时触发。

### 3.2 UI 示例

```
用户：推荐一个工具给我

助手：抱歉，我需要更具体的信息。请问你想要什么类型的开源工具？
[ ] 开发框架    [ ] 命令行工具    [ ] GUI 应用    [ ] 库/SDK
```

---

## 4. Step 3：本地搜索 + Step 4：LLM 推荐

### 4.1 搜索流程

```
意图明确 → 本地向量搜索 → 结果足够？（≥3个）
    ├→ 是 → 返回项目卡片
    └→ 否 → LLM 知识推荐（文字）
```

### 4.2 本地搜索

1. 提取关键词
2. 生成向量
3. 语义匹配
4. 返回项目卡片

### 4.3 LLM 推荐

**特点**：返回文字描述，不是项目卡片

**Prompt**：
```
你是一个开源项目推荐专家。用户需求是：「{用户意图}」

请基于你的知识，推荐 3-5 个相关开源项目。要求：
1. 项目必须是开源的
2. Star 数高、社区活跃
3. 项目真实存在

请用自然语言回答，像朋友推荐一样，包含：
- 项目名称和 GitHub URL
- 为什么推荐
- Star 数（估算）
```

### 4.4 展示示例

```
用户：推荐一个好用的图像处理工具

助手：
[项目卡片] Pillow - Python 图像处理基础库
[项目卡片] OpenCV - 计算机视觉库

根据你的需求，我推荐几个图像处理相关的开源项目：

1. **OpenCV** - github.com/opencv/opencv
   最流行的计算机视觉库，Star 超 7 万，支持多种语言。

2. **Pillow** - github.com/python-pillow/Pillow
   Python 图像处理的基础库，简单易用，Star 超 1 万。

3. **Sharp** - github.com/lovell/sharp
   Node.js 的高性能图像处理库...
```

## 6. 主题引导设计

### 6.1 设计理念

**允许适当闲聊，但不断引导回开源项目推荐**：
- 不生硬拒绝用户
- 用友好的方式引导
- 保持对话的自然流畅

### 6.2 Prompt 示例

**用户闲聊时**：
```
用户：你好

助手：你好！我是开源项目推荐助手。😊
你是想找什么类型的开源项目吗？比如：
- "推荐一个好用的 Python Web 框架"
- "找一个 Vue 状态管理库"
- "帮我推荐图像处理工具"
```

**用户偏离主题时**：
```
用户：今天天气怎么样？

助手：哈哈，这个我帮不了你～ 😄
不过我可以帮你找开源项目！比如：
- "推荐一个开源的笔记应用"
- "找个 AI 相关的开源项目"
你想了解什么类型的开源项目呢？
```

### 6.3 引导原则

1. **友好不生硬**：不直接拒绝，用"这个我帮不了你，但..."的方式
2. **自然过渡**：从用户话题自然过渡到开源项目
3. **提供选项**：给出具体的问题示例
4. **保持热情**：始终保持友好、热情的态度
