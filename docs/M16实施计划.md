## 2 初始化向导

### 2.1 功能概述

系统首次启动或需要切换仓库时，引导用户完成仓库的创建、选择或导入。

**核心价值**：
- **本地优先**：用户掌控数据，仓库位置由用户选择
- **零门槛**：简单直观，3步完成初始化
- **数据迁移**：支持从备份恢复

### 2.2 功能定位

类似 Obsidian 首次启动时的仓库选择界面，提供三种仓库获取方式：
1. **选择已有仓库**：打开之前创建的仓库
2. **创建新仓库**：新建本地仓库
3. **从备份导入**：恢复之前导出的仓库

### 2.3 触发条件

| 场景 | 说明 |
|------|------|
| **首次启动** | 系统首次启动时（无 last-vault.txt） |
| **无仓库状态** | 所有仓库都被删除后 |
| **手动入口** | 侧边栏/设置中提供入口，随时可进入 |

### 2.4 系统入口

在侧边栏底部提供"切换仓库"入口，点击打开此向导。

### 2.6 功能详情

#### 2.6.1 选择已有仓库

| 项目 | 说明 |
|------|------|
| 列表展示 | 显示所有已创建的仓库（名称、路径、项目数） |
| 点击选择 | 直接打开该仓库，进入系统 |
| 空状态 | 无已有仓库时，提示创建或导入 |

#### 2.6.2 创建新仓库

| 项目 | 说明 |
|------|------|
| 仓库名称 | 用户输入，默认"我的仓库" |
| 存储位置 | 用户选择，默认 `vaults/` 目录下 |
| 目录验证 | 检测目标目录是否已有仓库 |
| 创建并继续 | 创建仓库，进入步骤2初始化 |

#### 2.6.3 从备份导入

| 子步骤 | 说明 |
|--------|------|
| 选择备份 | 选择包含备份的目录（必须有 `os_compass.db` 和 `.cryptokey`） |
| 验证备份 | 检测备份文件完整性，显示验证结果 |
| 选择目标 | 选择导入到哪个目录 |
| 执行导入 | 复制备份文件到目标位置 |

#### 2.6.4 初始化仓库

| 步骤 | 说明 |
|------|------|
| 创建文件夹 | 在目标位置创建仓库目录 |
| 初始化数据库 | 创建 `os_compass.db` 和表结构 |
| 设置加密密钥 | 生成/复制 `.cryptokey` 文件 |
| 注册仓库 | 写入 last-vault.txt 和 vault-index.json |

### 2.7 数据结构

#### 2.7.1 仓库索引 (vault-index.json)

```json
{
  "version": 1,
  "vaults": [
    {
      "name": "工作仓库",
      "path": "D:\\Projects\\vaults\\work",
      "created_at": "2026-07-01T10:00:00Z"
    }
  ]
}
```

#### 2.7.2 备份验证结果

```typescript
interface BackupValidation {
  valid: boolean;
  error?: string;
  db_exists: boolean;
  key_exists: boolean;
  project_count?: number;
}
```

### 2.8 错误处理

| 场景 | 错误信息 | 处理方式 |
|------|----------|----------|
| 目录已存在仓库 | "该目录已是仓库目录" | 提示选择其他目录 |
| 备份目录无效 | "未找到有效的备份文件" | 提示检查目录 |
| 备份验证失败 | "缺少必要的备份文件" | 提示缺少哪些文件 |
| 目标目录不存在 | "目录不存在" | 自动创建或提示创建 |
| 权限不足 | "无法写入目标目录" | 提示选择其他目录 |

### 2.9 交互说明

| 操作 | 行为 |
|------|------|
| 点击已有仓库 | 直接打开该仓库，进入系统 |
| 点击"创建并继续" | 进入步骤2初始化流程（新建） |
| 点击"开始导入" | 进入步骤1.5导入流程 |
| 浏览备份目录 | 打开系统目录选择对话框 |
| 点击"验证备份" | 检测 `os_compass.db` 和 `.cryptokey` |
| 选择目标位置 | 选择导入到哪个目录 |
| 点击"开始导入" | 复制备份到目标位置 |
| 点击"返回" | 返回步骤1 |
| 点击"上一步" | 返回步骤1，修改仓库名称或位置 |
| 点击"下一步" | 执行初始化，完成后进入步骤3 |
| 点击"开始使用" | 初始化完成，进入系统 |

## 4 极简首页（home.html）

### 4.1 功能定位

产品级首页，提供极简的 URL 导入体验。

### 4.2 功能详情

| 功能点 | 说明 |
|--------|------|
| 极简输入框 | 大幅面居中输入框，粘贴 URL 自动识别平台 |
| 快速导入 | 输入即导入，无需多次点击 |
| 最近项目 | 下方显示最近导入的项目（最近 5 个） |
| 快捷入口 | 情报雷达、意图搜索入口（次要位置） |

### 4.3 设计参考

> **极简输入（消灭手动填表）**：界面上只有一个大大的输入框。用户只需要粘贴一个链接，敲击回车，操作就结束了。

### 4.4 参照

- 原型：`design-system/public/home.html`
