# M16: 初始化向导 + 主页增强 实施计划

> **二期功能标记**：本计划所有功能均为二期（Phase 2）功能。

---

## 1 概述

### 1.1 目标

| 模块 | 目标 |
|------|------|
| **初始化向导** | 系统首次启动时引导用户创建/选择仓库 |
| **功能入口页** | 聚合所有功能入口的设计系统原型页面 |
| **极简首页** | 单一大输入框，粘贴 URL 回车快速导入 |

### 1.2 核心价值

> **本地优先 (Local-First)**：用户掌控自己的数据，仓库位置由用户选择。

---

## 2 初始化向导

### 2.1 功能定位

类似 Obsidian 首次启动时的仓库选择界面，引导用户：
1. 选择已有仓库
2. 创建新仓库
3. 指定仓库存储位置

### 2.2 触发条件

- 系统首次启动时（无 last-vault.txt）
- 所有仓库都被删除后

### 2.3 交互流程

```
┌─────────────────────────────────────────────┐
│         OS-Compass 初始化向导               │
├─────────────────────────────────────────────┤
│                                             │
│   🗂️  选择已有仓库                          │
│   └── 显示已存在的仓库列表                   │
│   └── 点击选择，打开仓库                     │
│                                             │
│   ➕  创建新仓库                            │
│   └── 输入仓库名称                          │
│   └── 选择存储位置（默认 vaults/）           │
│   └── 点击创建                              │
│                                             │
│   📥  导入仓库                              │
│   └── 选择已有文件夹作为仓库                │
│   └── 验证并导入                            │
│                                             │
└─────────────────────────────────────────────┘
```

### 2.4 参照

- **Obsidian** 首次启动界面
- 原型：`design-system/public/home.html`（待完善）

### 3.3 参照

## 4 极简首页（home.html）

### 4.1 功能定位

产品级首页，提供极简的 URL 导入体验。

### 4.2 功能详情

| 功能点 | 说明 |
|--------|------|
| 极简输入框 | 大幅面居中输入框，粘贴 URL 自动识别平台 |
| 快速导入 | 输入即导入，无需多次点击 |
| 最近项目 | 下方显示最近导入的项目（最近 5 个） |
| 快捷入口 | 情报雷达、意图搜索入口（次要位置） |

### 4.3 设计参考

> **极简输入（消灭手动填表）**：界面上只有一个大大的输入框。用户只需要粘贴一个链接，敲击回车，操作就结束了。

### 4.4 参照

- 原型：`design-system/public/home.html`

## 8 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 用户跳过初始化 | 可能没有可用的仓库 | 强制必须完成初始化 |

| 仓库位置选择 | 用户困惑 | 提供合理的默认位置 |
