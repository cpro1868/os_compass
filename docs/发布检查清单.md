# 发布检查清单

每次工作完成后，必须执行以下步骤：

## 1. 编译验证

```bash
cd "G:/Projects/kimicode/os_compass/os-compass"
$env:PATH = "D:\Soft\msys64\mingw64\bin;" + $env:PATH
pnpm tauri build
```

## 2. 应用启动测试

验证新编译的 exe 能正常启动：

```bash
$env:PATH = "D:\Soft\msys64\mingw64\bin;" + $env:PATH
Start-Process -FilePath "G:\Projects\kimicode\os_compass\os-compass\src-tauri\target\release\os-compass.exe" -PassThru | 
    ForEach-Object { $proc = $_; Start-Sleep -Seconds 3; 
    if (!$proc.HasExited) { Write-Host "SUCCESS - PID: $($proc.Id)"; Stop-Process -Id $proc.Id -Force } 
    else { Write-Host "FAILED - Exit code: $($proc.ExitCode)" } }
```

## 5. 发布到 Previous 文件夹

```powershell
# 获取 AppData 路径
$appData = [Environment]::GetFolderPath("ApplicationData")
$dbDir = "$appData\com.administrator.os-compass"

# 清理 Previous 文件夹（只保留最新）
Remove-Item "G:\Projects\kimicode\os_compass\Previous\*" -Force

# 复制 exe 和依赖
Copy-Item "G:\Projects\kimicode\os_compass\os-compass\src-tauri\target\release\os-compass.exe" "G:\Projects\kimicode\os_compass\Previous\"
Copy-Item "G:\Projects\kimicode\os_compass\os-compass\src-tauri\target\release\WebView2Loader.dll" "G:\Projects\kimicode\os_compass\Previous\"

# 复制数据库文件
Copy-Item "$dbDir\os_compass.db" "G:\Projects\kimicode\os_compass\Previous\"
Copy-Item "$dbDir\settings.db" "G:\Projects\kimicode\os_compass\Previous\"
```

## 6. 独立运行验证

```powershell
Start-Process -FilePath "G:\Projects\kimicode\os_compass\Previous\os-compass.exe" -WorkingDirectory "G:\Projects\kimicode\os_compass\Previous" -PassThru | 
    ForEach-Object { $proc = $_; Start-Sleep -Seconds 4; 
    if (!$proc.HasExited) { Write-Host "PREVIOUS SUCCESS - PID: $($proc.Id)"; Stop-Process -Id $proc.Id -Force } 
    else { Write-Host "PREVIOUS FAILED - Exit code: $($proc.ExitCode)" } }
```
