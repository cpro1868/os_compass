## 12. 初始化命令备忘

```bash
# 1. 确认 Rust 环境
rustc --version
cargo --version

# 2. 安装 Tauri CLI
cargo install tauri-cli --version "^2.0"

# 3. 创建 Tauri 应用
npx create-tauri-app@latest
# 选择: React + TypeScript

# 4. 安装前端依赖
pnpm install

# 5. 安装额外前端依赖
pnpm add tailwindcss postcss autoprefixer
pnpm add zustand
pnpm add react-i18next i18next
pnpm add marked dompurify turndown
pnpm add @easy-mde/react
pnpm add recharts  # 统计图表

# 6. 启动开发服务器
pnpm tauri dev
```
