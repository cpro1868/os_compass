## 1 概述

## 2 功能详情

### 2.1 GitLab 扩展

**功能**：支持导入 GitLab 项目，获取项目详情、健康度评分。

| 功能点 | 说明 |
|--------|------|
| GitLab URL 解析 | 识别 gitlab.com 和私有 GitLab 实例 |
| API Token 配置 | 支持 Personal Access Token |
| 项目导入 | API 获取项目信息（名称、描述、星标、语言、提交活跃度） |
| 健康度评分 | GitLab 特有维度：CI/CD 配置、MR 合并率、issue 关闭率 |

**API 设计**：
```
GET /api/v4/projects/:id
GET /api/v4/projects/:id/repository/contributors
GET /api/v4/projects/:id/pipelines
```

### 2.2 Docker Hub 扩展

**功能**：支持导入 Docker Hub 镜像，获取镜像统计信息。

| 功能点 | 说明 |
|--------|------|
| 镜像解析 | 解析 official/namespace/image 格式 |
| 官方 API | https://hub.docker.com/v2/repositories/{name} |
| 数据获取 | 下载量、拉取趋势、星标、标签列表 |
| 项目卡片 | Docker 特有字段：基础镜像、Dockerfile、容器化程度 |

### 2.3 插件热加载

**功能**：支持加载本地目录中的第三方插件。

| 功能点 | 说明 |
|--------|------|
| 插件清单 | `manifest.json` 描述插件元数据 |
| 动态注册 | 运行时注册到 PluginManager |
| 生命周期 | init/start/stop/destroy |
| 隔离沙箱 | 插件错误不影响主程序 |

**清单文件格式**：
```json
{
  "id": "example-plugin",
  "name": "Example Plugin",
  "version": "1.0.0",
  "author": "Developer",
  "description": "A example plugin",
  "entry": "plugin.wasm",
  "permissions": ["network", "storage"]
}
```

### 2.4 插件市场 UI

**功能**：浏览、安装、卸载插件。

| 功能点 | 说明 |
|--------|------|
| 内置插件 | radar/search 显示状态 |
| 远程市场 | 插件列表（名称、描述、作者、下载量） |
| 安装/卸载 | 一键安装，本地卸载 |
| 插件详情 | 版本、权限、依赖、评分 |

### 2.5 备份恢复

**功能**：数据库备份与恢复。

| 功能点 | 说明 |
|--------|------|
| 自动备份 | 启动时检测，可配置备份数量 |
| 手动备份 | 用户触发备份 |
| 恢复功能 | 选择备份文件恢复 |
| 备份列表 | 显示备份时间、大小 |

### 2.6 新手引导

**功能**：首次使用引导流程。

| 功能点 | 说明 |
|--------|------|
| 欢迎页 | 介绍产品功能 |
| 仓库创建 | 创建第一个仓库 |
| LLM 配置 | 配置 AI 能力 |
| 第一个项目 | 导入第一个开源项目 |
| 引导完成 | 跳转到主界面 |

### 2.7 快捷键

**功能**：全局快捷键支持。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 打开命令面板/搜索 |
| `Ctrl+N` | 新建项目导入 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+/` | 打开快捷键帮助 |
| `Escape` | 关闭弹窗 |

        e.preventDefault();
        openCommandPalette();
      }
      // ... 其他快捷键
    };
    window.addEventListener('keydown', handler);
    return () => window.removeEventListener('keydown', handler);
  }, []);
