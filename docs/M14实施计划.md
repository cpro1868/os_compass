## 2 功能详情

### 2.1 GitLab 扩展（项目导入）

**功能**：支持从 GitLab 导入项目。

> **使用场景**：项目导入（用户输入 GitLab URL 导入新项目）

| 功能点 | 说明 |
|--------|------|
| GitLab URL 解析 | 识别 gitlab.com 和私有 GitLab 实例 |
| API Token 配置 | 支持 Personal Access Token（通过扩展配置） |
| 项目导入 | API 获取项目信息（名称、描述、星标、语言、提交活跃度） |
| 健康度评分 | GitLab 特有维度：CI/CD 配置、MR 合并率、issue 关闭率 |

**API 设计**：
```
GET /api/v4/projects/:id
GET /api/v4/projects/:id/repository/contributors
GET /api/v4/projects/:id/pipelines
```

### 2.2 Docker Hub 扩展（项目导入）

**功能**：支持从 Docker Hub 导入镜像信息。

> **使用场景**：项目导入（用户输入 Docker 镜像名导入信息）

| 功能点 | 说明 |
|--------|------|
| 镜像解析 | 解析 official/namespace/image 格式 |
| 官方 API | https://hub.docker.com/v2/repositories/{name} |
| 数据获取 | 下载量、拉取趋势、星标、标签列表 |
| 项目卡片 | Docker 特有字段：基础镜像、Dockerfile、容器化程度 |

### 2.3 插件热加载

**功能**：支持加载本地目录中的第三方插件。

> **技术方案**：先实现目录加载（简单），WASM 热加载后续实现。

| 功能点 | 说明 |
|--------|------|
| 插件目录 | 扫描 `${AppData}/.os-compass/plugins/` 目录 |
| 插件清单 | `manifest.json` 描述插件元数据 |
| 动态注册 | 运行时注册到 PluginManager |
| 生命周期 | init/start/stop/destroy |
| 隔离沙箱 | 插件错误不影响主程序 |

**清单文件格式**：
```json
{
  "id": "example-plugin",
  "name": "Example Plugin",
  "version": "1.0.0",
  "author": "Developer",
  "description": "A example plugin",
  "entry": "plugin.js",
  "permissions": ["network", "storage"]
}
```

**注意**：entry 目前使用本地 JS 文件路径，WASM 支持后续扩展。

### 2.4 本地插件管理

**功能**：管理本地已安装的插件。

> **注意**：本期不包含远程插件市场，仅实现本地插件管理。

| 功能点 | 说明 |
|--------|------|
| 插件列表 | 显示 `${AppData}/.os-compass/plugins/` 下的插件 |
| 插件详情 | 版本、作者、描述、权限 |
| 启用/禁用 | 开关控制插件是否加载 |
| 卸载插件 | 删除插件目录 |

**注意**：radar/search 作为内置插件，始终存在且可启用/禁用。

### 2.5 备份恢复

**功能**：仓库文件夹级别的备份与恢复。

| 功能点 | 说明 |
|--------|------|
| 作用域 | 单个仓库，只备份当前仓库目录下的所有文件 |
| 备份粒度 | 整个仓库文件夹打包为 .zip |
| 手动备份 | 用户输入文件名，保存到用户选择的位置 |
| 自动备份 | 按表达式自动命名，保存到用户选择的位置 |
| 同名处理 | 覆盖 |
| 恢复目标 | 用户选择目录（新仓库） |
| 目录冲突 | 提示"目录不为空"，用户确认后覆盖 |
| 恢复验证 | 数据库文件存在、密钥文件存在、版本兼容 |

**注意**：备份恢复是文件级别操作，直接操作 .zip 文件，**不需要数据库表**记录备份历史。备份列表直接从用户选择的目录读取 .zip 文件。

### 2.6 新手引导

**功能**：首次使用引导流程。

| 功能点 | 说明 |
|--------|------|
| 欢迎页 | 介绍产品功能 |
| 仓库创建 | 创建第一个仓库 |
| LLM 配置 | 配置 AI 能力 |
| 第一个项目 | 导入第一个开源项目 |
| 引导完成 | 跳转到主界面 |

### 2.7 快捷键

**功能**：全局快捷键支持。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 打开命令面板/搜索 |
| `Ctrl+N` | 新建项目导入 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+/` | 打开快捷键帮助 |
| `Escape` | 关闭弹窗 |
