## 一、问题现象（用户验收反馈）

1. **本地向量搜索严重不相关**：搜索"音频工具"出现多个完全不相关工具；搜索"地图工具"推荐了一堆开源项目集、useSend 等无关项目。
2. **点击"让大模型再推荐 5 个"后没有任何信息返回**：按预期应将用户问题直接丢给 LLM 搜索并返回结果。

---

## 二、根因分析（基于代码与 debug.log 取证）

### 问题 1：本地向量搜索返回不相关项目

| # | 根因 | 证据 |
|---|------|------|
| R1 | **`semantic_search` 无相似度阈值**：余弦相似度排序后直接取 top-10 返回，哪怕相似度只有 0.1~0.3 的垃圾匹配也全部当作"相关项目"展示 | `embedding.rs:178-232`：`scored.truncate(limit)` 无任何过滤 |
| R2 | **垃圾结果挤掉 LLM 兜底**：`local_results.len() >= 3` 就不再调用 LLM 知识推荐。10 条不相关结果直接堵死 LLM 推荐，用户只看到垃圾 | `plugins/search.rs:215-226` |
| R3 | **向量数据质量存疑（待诊断）**：`project_embeddings` 虚表定义是 `FLOAT[1536]`，而 bge-m3 是 1024 维；且 42 个项目仅 20+ 个有向量、旧向量可能是无 languages 的旧格式。`cosine_similarity` 用 `min(len)` 计算，维度混用会产生无意义分数 | `embedding.rs:163`、`cosine_similarity` |
| R4 | **项目集（awesome-list）语义污染**：此类项目描述包含海量工具名，与任何查询都有中等相似度，无阈值时必然霸榜 | 用户看到的"开源项目集"即此类 |

### 问题 2：点击"再推荐 5 个"没有任何信息返回

debug.log（`%APPDATA%\.os-compass\debug.log`）证明**后端两次都成功返回了 5 条**（2026-09-06 22:47:00 / 22:47:09），问题 100% 在前端：

| # | 根因 | 证据 |
|---|------|------|
| R5 | **去重后可能新增 0 条但无提示**：追加前按 URL 去重，若 LLM 推荐的项目 URL 与已有结果重复，全部被过滤；此时 `appended.length`（原始 5 条）> 0，不弹"暂无更多推荐"Toast，界面毫无变化 | `SearchView.tsx:288-297`：`merged` 可能等于 `existing` |
| R6 | **等待 20~30 秒期间只有按钮内小 spinner**，结果追加在列表末尾、无滚动/高亮，感知上就是"没反应" | `ResultsList` 组件实现 |

---

## 三、修复方案

### A. 搜索质量（问题 1）

1. `semantic_search` 增加相似度阈值过滤（默认 `cosine >= 0.45`，常量可调），低于阈值直接丢弃。
2. `three_layer_search` 兜底条件改为：**阈值过滤后高相关结果 < 3 条时触发 LLM 知识推荐**。
3. **先诊断后修改**：执行一次性诊断，核对库内向量维度/数量/格式与当前模型（bge-m3, 1024 维）一致性，输出报告（不改数据）。
4. 单元测试：阈值过滤、低分丢弃、LLM 兜底触发条件。

### B. 再推荐反馈（问题 2）

1. 点击后显示**内联 loading 区域**（卡片大小的占位提示，不再只是按钮内小 spinner）。
2. 返回后按"新增条数"处理：
   - `新增 0 条` → Toast 提示"推荐的项目已在结果中"；
   - `> 0 条` → 追加 + 自动展开 + 滚动定位到新增卡片。
3. 后端 debug log 增加返回的 URL 清单，便于下次 GUI 取证对账。
4. 单元测试：去重全命中时弹 Toast、正常追加可见。

### C. 验证与交付

- `pnpm test` + `pnpm typecheck` + `cargo check --lib` + `pnpm tauri build`
- 产物同步 `Previous/`
- 用户 GUI 验收：搜索"音频工具/地图工具"看相关性 + 点击"再推荐 5 个"看反馈

## 四、风险评估

| 风险 | 应对 |
|------|------|
| 阈值 0.45 可能过滤掉部分中等相关结果 | 阈值做成常量，验收后可调 |
| 诊断若发现维度混用/旧格式向量 | 需重建全部向量（提示用户一键操作） |
| 影响面 | 不改数据库 schema、不触碰加密/仓库切换逻辑，仅限搜索链路 3 个文件（`embedding.rs`、`plugins/search.rs`、`SearchView.tsx`） |
