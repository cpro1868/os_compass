## 1 当前问题

### 1.1 代码块解析问题暴露的缺陷

| 问题 | 影响 |
|------|------|
| 切片范围无效（`json_str[7..0]`） | 程序行为未定义，可能卡死 |
| release 模式 `println!` 不输出 | 日志无法观察 |
| 错误未及时反馈 | 用户看到 loading 状态，不知道发生了什么 |
| 日志路径错误 | 浪费排查时间 |

### 1.2 问题分类

```
异常
├── 网络异常（超时、连接失败）
├── 数据解析异常（JSON 解析失败、切片越界）
├── 业务异常（LLM 调用失败、数据库错误）
└── 系统异常（文件权限、路径不存在）
```

## 2 异常处理保障方案

### 2.1 后端异常处理原则

| 原则 | 说明 |
|------|------|
| **防御性编程** | 外部输入必须验证后再使用 |
| **早失败** | 发现问题立即返回错误，不要等到后面才暴露 |
| **明确错误** | 使用具体的错误类型，不是笼统的 String |
| **日志记录** | 每次错误都要记录日志，包含上下文信息 |

### 2.2 Rust 错误处理规范

#### 2.2.1 使用 `?` 而非 `unwrap()`

```rust
// ❌ 错误：panic 可能导致程序崩溃
let value = some_option.unwrap();

// ✅ 正确：返回明确的错误
let value = some_option.ok_or_else(|| MyError::InvalidInput("value is None".to_string()))?;
```

#### 2.2.2 切片操作必须边界检查

```rust
// ❌ 错误：可能 panic
let slice = &str[start + 7..start + end];

// ✅ 正确：边界检查
if end > start && end <= str.len() && start < str.len() {
    let slice = &str[start + 7..end];
} else {
    return Err(MyError::InvalidRange);
}
```

#### 2.2.3 JSON 解析必须处理失败

```rust
// ❌ 错误：parse 失败直接 panic
let parsed: MyStruct = serde_json::from_str(json).unwrap();

// ✅ 正确：处理解析失败
match serde_json::from_str::<MyStruct>(json) {
    Ok(parsed) => Ok(parsed),
    Err(e) => {
        log::error!("JSON parse failed: {} - input: {}", e, &json[..json.len().min(200)]);
        Err(MyError::ParseError(e.to_string()))
    }
}
```

### 2.3 统一错误类型

```rust
#[derive(Debug, Error)]
pub enum AppError {
    #[error("网络错误: {0}")]
    Network(String),
    
    #[error("数据解析错误: {0}")]
    Parse(String),
    
    #[error("LLM 调用失败: {0}")]
    Llm(String),
    
    #[error("数据库错误: {0}")]
    Database(String),
    
    #[error("业务错误: {0}")]
    Business(String),
    
    #[error("系统错误: {0}")]
    System(String),
}
```

## 3 日志保障方案

### 3.1 日志级别定义

| 级别 | 使用场景 | 示例 |
|------|----------|------|
| **ERROR** | 错误，需要调查 | JSON 解析失败、数据库连接失败 |
| **WARN** | 警告，可能有问题 | 配置缺失、使用了默认值 |
| **INFO** | 一般信息 | 函数入口、重要流程节点 |
| **DEBUG** | 调试信息 | 变量值、中间状态 |

### 3.2 日志输出策略

```rust
// ✅ 使用 log crate，支持 release 模式输出
log::info!("[模块] 操作描述, 参数: {:?}", params);
log::error!("[模块] 错误: {}, 上下文: {:?}", error, context);

// ❌ 不要使用 println!（release 模式不输出）
println!("Debug info");  // 不输出
```

### 3.3 日志内容规范

```
[时间] [级别] [模块] 消息
[2026-07-24 10:30:00.123] [ERROR] [AI] JSON parse failed: unexpected end of input, json_len=50, json_preview="{\"summary\": \"..."
```

**必须包含的上下文**：
- 操作名称
- 关键参数（脱敏后）
- 错误详情
- 堆栈信息（如果是 panic）

### 3.4 日志文件管理

| 配置 | 值 | 说明 |
|------|-----|------|
| 日志目录 | `%AppData%\.os-compass\logs\` | 与数据库同目录 |
| 日志文件名 | `app.log` | 统一日志文件 |
| 最大文件大小 | 10MB | 超过后轮转 |
| 保留数量 | 5 个 | 保留最近 5 个日志文件 |

## 6 代码示例

### 6.1 安全的代码块解析

```rust
fn extract_json_block(response: &str) -> Result<String, AppError> {
    let trimmed = response.trim();
    
    // 查找代码块开始
    let block_start = if let Some(pos) = trimmed.find("```json") {
        pos + 7  // "```json".len()
    } else if let Some(pos) = trimmed.find("```") {
        pos + 3  // "```".len()
    } else {
        return Err(AppError::Parse("No code block found".to_string()));
    };
    
    // 查找代码块结束
    let remaining = &trimmed[block_start..];
    let block_end_marker = remaining.find("```")
        .ok_or_else(|| AppError::Parse("No closing code block".to_string()))?;
    
    // 边界检查
    let end = block_start + block_end_marker;
    if end <= block_start {
        return Err(AppError::Parse(format!(
            "Invalid code block range: start={}, end={}", 
            block_start, end
        )));
    }
    
    let json_str = trimmed[block_start..end].trim();
    log::debug!("[AI] Extracted JSON block, len={}", json_str.len());
    
    Ok(json_str.to_string())
}
```

fn analyze_project(id: i64) -> Result<AiResult, AppError> {
    log::info!("[AI] Starting analyze_project, id={}", id);
    
    let project = get_project(id)
        .map_err(|e| {
            log::error!("[AI] Failed to get project: id={}, error={}", id, e);
            AppError::Database(e.to_string())
        })?;
    
    let llm_response = llm::chat(&prompt)
        .await
        .map_err(|e| {
            log::error!("[AI] LLM call failed: id={}, error={}", id, e);
            AppError::Llm(e.to_string())
        })?;
    
    let parsed = parse_llm_response(&llm_response)
        .map_err(|e| {
            log::error!("[AI] JSON parse failed: id={}, error={}, response_len={}", 
                id, e, llm_response.len());
            AppError::Parse(e.to_string())
        })?;
    
    log::info!("[AI] analyze_project complete, id={}, summary_len={}", 
        id, parsed.summary.as_ref().map(|s| s.len()).unwrap_or(0));
    
    Ok(parsed)
}
```
