## 3 功能需求（更新）

### 3.1 当前问题

| # | 问题 | 根因 | 影响 |
|---|------|------|------|
| 1 | 搜索质量差 | 使用 LIKE 模糊匹配，无语义理解 | 返回结果不准确 |
| 2 | 缺少项目信息 | 只返回 name/url/description | 无法显示星标、活跃度 |
| 3 | 界面简陋 | 结果弹窗展示 | 用户体验差 |
| 4 | 无向量支持 | 未集成 sqlite-vec | 无法语义搜索 |

### 3.2 修复方案（M17）

| # | 问题 | 修复方案 | 实现方式 |
|---|------|----------|-----------|
| 1 | 搜索质量 | 向量语义搜索 | sqlite-vec + embedding |
| 2 | 项目信息 | 关联 projects 表 | JOIN 获取完整信息 |
| 3 | 界面 | ChatGPT 风格 | 聊天区直接展示卡片 |
| 4 | 向量支持 | sqlite-vec 扩展 | 仓库库初始化时加载 |

### 3.3 向量搜索流程

```
用户输入 → 生成查询向量 → vec_match → 语义匹配 Top N
```

> 注：不需要"LLM 提取语义意图"这一步，直接用 query 生成 embedding

```sql
-- 向量搜索示例（sqlite-vec）
SELECT rowid, distance
FROM project_embeddings
WHERE embedding MATCH '[...]'
ORDER BY distance
LIMIT 20;
```

## 8 向量搜索增强

### 8.1 技术方案

**向量数据库**：与仓库库**同一文件**（`os_compass.db`）

| 组件 | 存储位置 | 说明 |
|------|----------|------|
| 项目数据 | 仓库库 `os_compass.db` | projects 表 |
| 向量数据 | 仓库库 `os_compass.db` | project_embeddings 表 |
| sqlite-vec 扩展 | 系统库目录 | 全局共享 |

> 向量数据和项目数据在同一文件，直接 JOIN 查询，无需跨文件关联。

### 8.2 数据模型

**向量表**（在仓库库中）：
```sql
-- 加载 sqlite-vec 扩展
PRAGMA load_extension('vec0');

-- 项目向量表
CREATE VIRTUAL TABLE IF NOT EXISTS project_embeddings USING vec0(
    embedding float[1536]
);
```

### 8.3 双轨搜索架构

```
用户输入 → 并行执行
├── 本地向量搜索：query → 生成 embedding → vec_match（快，< 100ms）
└── LLM 联网搜索：query → LLM 搜索 GitHub/Gitee（慢，3-10s）
```

| 轨道 | 搜索范围 | 延迟 |
|------|----------|------|
| 第一轨 | 本地向量搜索 | < 100ms |
| 第二轨 | LLM 联网搜索 | 3-10s |

### 8.4 仓库初始化影响

**向量表存储位置**：仓库库 `os_compass.db`（跟随仓库切换）

**sqlite-vec 扩展**：从系统库读取路径，全局共享

**仓库初始化时操作**：

| 操作 | 向量表创建 | 说明 |
|------|------------|------|
| create_vault | ✅ 自动创建 | 新仓库创建时 |
| open_vault | ✅ IF NOT EXISTS | 打开时检查并创建 |
| import_vault | ✅ IF NOT EXISTS | 导入后打开时 |

**初始化流程**：
```
1. 创建数据库文件
2. 创建业务表（projects, categories 等）
3. 创建向量虚拟表（project_embeddings）
4. 创建 config.json
5. （sqlite-vec 扩展从系统库读取路径，动态加载）
```

### 8.5 实现文件

| 文件 | 职责 |
|------|------|
| `src-tauri/src/embedding.rs` | 向量生成和搜索（sqlite-vec + LLM embedding） |

### 8.7 降级策略

| 场景 | 处理方式 |
|------|----------|
| vss 扩展加载失败 | 回退到关键词 LIKE 搜索 |
| Embedding API 未配置 | 禁用向量搜索，仅 LLM 联网 |
| 向量搜索不可用 | 意图搜索降级为关键词匹配 |
