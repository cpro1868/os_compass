## 3 意图搜索问题分析

### 3.1 当前问题

| # | 问题 | 根因 | 影响 |
|---|------|------|------|
| 1 | 搜索质量差 | 使用 LIKE 模糊匹配，无权重 | 返回结果不准确 |
| 2 | 缺少项目信息 | 只返回 name/url/description | 无法显示星标、活跃度 |
| 3 | 评分不合理 | match_score 固定值 | 无法排序 |
| 4 | 缓存未填充 | 项目导入时未同步 | 二三层搜索无数据 |

### 3.2 修复方案

| # | 问题 | 修复方案 | 实现方式 |
|---|------|----------|-----------|
| 1 | 搜索质量 | 关键词分词 + 权重 | 使用空格分词，名称权重 3x，描述权重 1x |
| 2 | 项目信息 | 关联 projects 表 | JOIN 获取完整信息 |
| 3 | 评分计算 | 活跃度 = stars * 0.7 + forks * 0.3 | SQL 计算 |
| 4 | 缓存填充 | 项目导入时写入 | 在 import 流程中调用 cache_update |

### 3.3 搜索质量优化

**优化前**：
```sql
WHERE name LIKE '%query%' OR description LIKE '%query%'
```

**优化后**：
```sql
-- 关键词分词 + 权重
SELECT *,
  (CASE WHEN name LIKE '%kw1%' THEN 3 ELSE 0 END +
   CASE WHEN name LIKE '%kw2%' THEN 3 ELSE 0 END +
   CASE WHEN description LIKE '%kw1%' THEN 1 ELSE 0 END +
   ...) as relevance
FROM projects
WHERE relevance > 0
ORDER BY relevance DESC, stars DESC
LIMIT 20
```

### Task 4: 意图搜索后端优化

**文件**：`src-tauri/src/plugins/search.rs`

**优化内容**：
1. 分词 + 权重查询
2. JOIN projects 表获取完整信息
3. 计算活跃度评分
4. 项目导入时同步到 cache

**伪代码**：
```rust
// 搜索优化
pub async fn search_projects(query: &str) -> Result<Vec<ProjectMatch>> {
    let keywords: Vec<&str> = query.split_whitespace().collect();

    // 构建加权查询
    let mut sql = String::new();
    sql.push_str("SELECT p.*, ");
    for (i, kw) in keywords.iter().enumerate() {
        let weight = if i == 0 { 3.0 } else { 1.0 };
        sql.push_str(&format!(
            "CASE WHEN LOWER(p.name) LIKE '%{}%' THEN {} ELSE 0 END + ",
            kw, weight
        ));
    }
    sql.push_str("0 as relevance ");

    // 关联 projects 表获取完整信息
    sql.push_str("FROM search_cache c JOIN projects p ON c.url_hash = p.url ");
    sql.push_str("ORDER BY relevance DESC, p.stars DESC LIMIT 20");
}
```
