```
│ │ProjectSvc│ │CategorySvc│ │PluginSvc │ │AISvc   │       │
│ └─────────┘ └─────────┘ └─────────┘ └─────────┘       │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐                   │
│ │DownloadSvc│ │CryptoSvc │ │SettingsSvc│                   │

                      │

                      │

│                   Data Layer                             │
│   SQLite (WAL) / OS KeyStore / FileSystem              │
└─────────────────────────────────────────────────────────┘
```

#### 4.1.2 技术选型评估

| 技术选型 | 评估 | 推荐度 |
|----------|------|--------|
| Tauri 2.0 | 轻量化（10MB vs Electron 150MB）、Rust 后端、成熟生态 | ⭐⭐⭐⭐⭐ |
| React 18 + TypeScript 5 | 生态成熟、类型安全、AI 辅助开发友好 | ⭐⭐⭐⭐ |
| Zustand | 轻量、无 Provider 嵌套、适合桌面应用 | ⭐⭐⭐⭐ |
| Tailwind CSS | 原子化、开发效率高、设计一致性好 | ⭐⭐⭐⭐ |
| SQLite (WAL) | 本地优先、零部署、够用 | ⭐⭐⭐⭐⭐ |
| Rust 1.75+ | 内存安全、高性能、学习曲线陡峭但可控 | ⭐⭐⭐⭐ |

**架构优点**：
1. **插件化设计**：平台解耦，新增平台仅需实现接口
2. **本地优先**：数据本地存储，隐私保障
3. **容错降级**：AI/网络失败不影响核心功能
4. **类型安全**：TypeScript + Rust 类型覆盖

**架构风险**：
1. **Rust 学习曲线**：建议 AI 辅助 + 详细设计参考
2. **插件热加载**：二期功能，一期可暂不实现
