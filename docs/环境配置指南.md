## 一、环境说明

| 组件 | 说明 | 状态 |
|------|------|------|
| **MSYS2** | 本机 VS C++ 安装有问题，改用 MSYS2 环境 | ✅ 已安装 |
| **MSYS2 安装路径** | `D:\Soft\msys64` | - |
| **UCRT64 环境** | MSYS2 的 C 运行时环境 | ✅ 已配置 |
| **MinGW 工具链** | GCC、Make 等编译工具 | ✅ 通过 MSYS2 安装 |

### 1.2 为什么使用 MSYS2？

| 方案 | 状态 | 说明 |
|------|------|------|
| Visual Studio C++ | ❌ 安装失败 | 本机安装遇到问题 |

## 二、MSYS2 环境详情

### 2.1 安装路径

```
D:\Soft\msys64\
├── ucrt64\           # UCRT64 环境（C 运行时）
│   └── bin\         # 可执行文件
├── mingw64\         # MinGW64 环境
├── usr\
│   └── bin\         # Unix 工具（ls, rm 等）
└── msys2.ini        # 配置文件
```

### 2.2 关键命令

| 命令 | 路径 | 说明 |
|------|------|------|
| `gcc` | `D:\Soft\msys64\mingw64\bin\gcc.exe` | C 编译器 |
| `g++` | `D:\Soft\msys64\mingw64\bin\g++.exe` | C++ 编译器 |
| `make` | `D:\Soft\msys64\usr\bin\make.exe` | Make 工具 |
| `clang` | `D:\Soft\msys64\mingw64\bin\clang.exe` | Clang 编译器（可选） |

### 2.3 环境变量配置

#### PATH 配置

```powershell
# 用户环境变量或系统环境变量中添加：
# 优先级从高到低：

D:\Soft\msys64\mingw64\bin
D:\Soft\msys64\ucrt64\bin
D:\Soft\msys64\usr\bin
```

#### 网络代理配置

> **重要**：如果遇到网络连接问题，需要配置代理。

```powershell
# HTTP/HTTPS 代理（用于 MSYS2 pacman、cargo 等）
$env:HTTP_PROXY = "http://127.0.0.1:8964"
$env:HTTPS_PROXY = "http://127.0.0.1:8964"

# PowerShell 永久设置
[System.Environment]::SetEnvironmentVariable("HTTP_PROXY", "http://127.0.0.1:8964", "User")
[System.Environment]::SetEnvironmentVariable("HTTPS_PROXY", "http://127.0.0.1:8964", "User")

# MSYS2 pacman 代理配置
# 编辑 D:\Soft\msys64\etc\pacman.conf，添加：
# XferCommand = /usr/bin/curl -L --proxy http://127.0.0.1:8964 -o %o %u
```

#### MSYS 环境变量

```powershell
# MSYS2 相关环境变量
MSYS_ROOT=D:\Soft\msys64
MSYS_HOME=D:\Soft\msys64\home\<用户名>
```

## 六、常见问题

### 6.1 GCC 找不到

**问题**：`error: linker 'gcc' not found`

**解决**：
```powershell
# 确认 MSYS2 环境变量已配置
$env:PATH = "D:\Soft\msys64\mingw64\bin;" + $env:PATH
$env:PATH = "D:\Soft\msys64\ucrt64\bin;" + $env:PATH

# 验证
gcc --version
```

### 6.2 Rust 编译失败

**问题**：`could not find gcc`

**解决**：
1. 确认 MSYS2 环境变量已添加到 PATH
2. 重启终端或重新加载环境变量
3. 确认 Rust 使用 MinGW 工具链

```powershell
# 查看 Rust 使用的工具链
rustup show

# 如果显示 MSVC，切换到 MinGW
rustup set default-host x86_64-pc-windows-gnu
```

### 6.3 WebView2 缺失

**问题**：`WebView2 runtime not found`

**解决**：
1. Windows 10 (2020 Update) 及以上版本自带 WebView2
2. 如遇问题，下载安装：https://developer.microsoft.com/en-us/microsoft-edge/webview2/
