## 一、目录结构

### 系统库（Roaming）

位置：`%APPDATA%\.os-compass\`

```
Roaming\.os-compass\
├── vault-index.json          # 仓库索引（包含所有仓库路径）
├── last-vault.txt           # 当前仓库路径
├── plugins.db               # 插件配置
├── os_compass.db            # 默认仓库数据库
├── .cryptokey               # 默认仓库密钥
├── config.json              # 默认仓库配置
├── settings.db              # 应用设置
├── system_settings.db       # 系统设置
└── logs\                   # 日志目录
```

### 仓库库（用户自定义）

位置：用户选择的任意目录

```
用户选择目录\
├── os_compass.db           # 仓库数据库
├── .cryptokey              # 仓库密钥
└── config.json             # 仓库配置
```

## 二、代码规范

### 禁止事项

1. ❌ 禁止在代码中硬编码路径
2. ❌ 禁止使用 `app_local_data_dir()` 获取仓库路径（Tauri 2.0 在 Windows 返回 Roaming）
3. ❌ 禁止直接拼接 `APPDATA + "\\xxx"`

### 必须事项

1. ✅ 必须使用统一的路径模块获取路径
2. ✅ 必须使用 `directories::BaseDirs` 获取系统目录
3. ✅ 必须明确定义系统库目录常量

## 三、路径模块设计

### 新建 `src-tauri/src/app_paths.rs`

```rust
use directories::BaseDirs;
use std::path::PathBuf;

pub struct AppPaths {
    pub system_dir: PathBuf,
}

impl AppPaths {
    pub fn new() -> Self {
        let base_dirs = BaseDirs::new()
            .expect("Cannot determine user directories");
        
        // 系统库固定在 Roaming\.os-compass\
        let system_dir = base_dirs.data_dir().join(".os-compass");
        
        Self { system_dir }
    }
    
    pub fn system_file(&self, filename: &str) -> PathBuf {
        self.system_dir.join(filename)
    }
}
```

### 系统库文件常量

```rust
// 系统库文件名常量
```

## 四、迁移计划

### 现状问题

| 问题 | 位置 |
|------|------|
| `get_vaults_root` 返回 Local 目录 | vault.rs, vault_cmd.rs |
| `app_local_data_dir()` 返回 Roaming | lib.rs |
| 硬编码 APPDATA 拼接 | vault.rs:364, radar_cmd.rs:66 |

### 迁移步骤

1. 创建 `app_paths.rs` 统一路径模块
2. 替换所有 `get_vaults_root` 调用
3. 替换所有系统库文件路径获取
4. 移除硬编码 APPDATA 拼接
5. 验证构建

| 风险 | 影响 | 缓解 |

| 路径变更导致数据丢失 | 高 | 先备份再迁移 |
| 旧版本数据兼容 | 中 | 支持读取旧路径 |
