# M13: 系统插件管理 + 意图搜索 + 情报雷达 实施计划

> **二期功能标记**：本计划所有功能均为二期（Phase 2），不在 MVP 范围内。
> **参照规范**：`docs/插件接入规范.md`、`docs/需求确认文档.md` §10-12、`docs/数据库设计说明书.md` §9、`docs/API接口设计说明书.md` §3.14-3.16、`docs/详细设计说明书.md` §4.1.7-4.1.10

**目标：** 实现二期 M13 功能：系统插件管理基础设施、信息源引擎、情报雷达插件（RSS/网站/TG 监控 + 收件箱）、意图搜索插件（三层优先级搜索 + ChatGPT 对话 UI）。

**架构：** 三层架构——底层是插件管理基础设施（FeaturePlugin trait + PluginRegistry + PluginManager），中层是信息源引擎（SourceAdapter trait + 四种适配器 + LLM 解析流水线），上层是两个功能插件实现（RadarPlugin + SearchPlugin）。插件数据库支持四种模式（main/global/vault/none），通过路径规则表达式声明，详见 `docs/插件接入规范.md`。前端新增雷达收件箱视图和意图搜索视图。

**技术栈：** Rust + Tauri 2.0 + React 19 + TypeScript + Tailwind CSS 4 + SQLite + Tokio + feed-rs + reqwest

- [ ] **Step 2: 实现 SearchPlugin 核心逻辑**

`three_layer_search(query, context)` 函数：
1. 调用 LLM 提取关键词（构建 prompt，调用 crate::llm，解析返回的关键词列表）
2. 第一层：在主库 projects 表中按关键词 LIKE 搜索，构建 ProjectMatch（source='local'）

`WebSearchStrategy` 枚举 + `web_search(query, strategy)` 函数：GitHub Search API 方案用 reqwest 调用 `https://api.github.com/search/repositories?q={query}`，Tavily 方案调用 Tavily API，WebCrawl 方案调用 web2md 爬取搜索引擎，Disabled 返回空 Vec。
