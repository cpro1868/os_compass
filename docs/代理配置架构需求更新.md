# 代理配置架构需求更新

**日期**: 2026-07-02
**状态**: 待实现

---

## 1. 问题背景

当前代理配置存在以下问题：
1. **GitHub 代理**：配置在扩展页（`github_proxy` 变量），但全局设置里也有一个未区分用途的 `proxy_git_only` 选项
2. **LLM 代理**：文档说应该支持，但实际代码中 `reqwest::Client` 没有配置代理
3. **Git Clone 代理**：使用全局设置，通过环境变量注入

用户反馈：
> 目前的代理设置，是只负责 Github的，还是说整个项目里都用到了这个代理？按道理，这个代理应该只负责 Github的扩展配置里才用这个，那么就有一个问题了，调用LLM有可能也需要用到代理，因此，设置里的大模型选项卡，也需要一个代理设置，一旦设置，那么使用大模型的时候就需要通过代理了。

---

## 2. 代理架构设计

### 2.1 代理分层模型

| 代理用途 | 配置位置 | 实现方式 | 优先级 |
|---------|---------|---------|-------|
| GitHub API | 扩展配置（`github_proxy`） | 插件内部使用 | 高 |
| Gitee API | 扩展配置（`gitee_proxy`） | 插件内部使用 | 高 |
| LLM API | LLM 设置页（`llm_proxy_*`） | reqwest client 配置 | 高 |
| Git Clone | 全局设置（`proxy_*`） | 环境变量注入 | 中 |
| 爬虫服务 | 全局设置（`proxy_*`） | 命令行参数 | 中 |

### 2.2 当前 vs 目标架构

**当前架构**：
```
全局代理 (proxy_*) ─┬─> Git Clone（环境变量）
                    ├─> 爬虫服务（命令行参数）
                    └─> LLM（未实现 ❌）
                    
扩展代理 (github_proxy) ──> GitHub API（插件内部）
```

**目标架构**：
```
LLM代理 (llm_proxy_*) ──> LLM API（reqwest 配置）
                   
GitHub代理 (github_proxy) ──> GitHub API（插件内部）

全局代理 (proxy_*) ─┬─> Git Clone（环境变量）
                    └─> 爬虫服务（命令行参数）
```

### 3.2 LLM Client 改造

**改造前**：
```rust
pub async fn chat(&self, messages: Vec<LlmMessage>) -> Result<String, String> {
    let client = reqwest::Client::new();  // 无代理
    // ...
}
```

**改造后**：
```rust
pub async fn chat(&self, messages: Vec<LlmMessage>, proxy_url: Option<String>) -> Result<String, String> {
    let mut client_builder = reqwest::Client::builder();
    
    if let Some(proxy) = proxy_url {
        client_builder = client_builder.proxy(
            reqwest::Proxy::http(&proxy)?  // HTTP 代理
                .https_proxy(&proxy)?       // HTTPS 代理
                .all(&proxy)?              // 其他协议代理
        );
    }
    
    let client = client_builder.build()?;
    // ...
}
```

### 3.3 LLM Client 初始化

```rust
impl LlmClient {
    pub fn from_settings() -> Option<Self> {
        let settings = SETTINGS.lock().ok()?;
        let settings = settings.as_ref()?;
        let s = settings.get_settings();
        
        let proxy_url = if s.llm_proxy_enabled && !s.llm_proxy_host.is_empty() {
            Some(build_proxy_url(
                &s.llm_proxy_protocol,
                &s.llm_proxy_host,
                s.llm_proxy_port,
                &s.llm_proxy_username,
                &s.llm_proxy_password,
            ))
        } else {
            None
        };
        
        Some(Self {
            api_url: s.llm_api_base,
            api_key: s.llm_api_key,
            model: s.llm_model,
            proxy_url,
        })
    }
    
    pub async fn chat(&self, messages: Vec<LlmMessage>) -> Result<String, String> {
        // 使用 self.proxy_url 配置代理
    }
}
```
