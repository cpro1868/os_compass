### 2.4 NPM 评价体系

#### 2.4.1 核心指标

| 指标 | 字段 | 说明 | 评分权重 |
|------|-------|------|----------|
| 下载量 | downloads | 月下载量 | 30% |
| 维护状态 | version | 是否落后 | 20% |
| 依赖健康 | dependencies | 依赖是否安全 | 15% |
| 社区活跃 | maintainers | 维护者数量 | 15% |
| 许可证 | license | 是否开源 | 10% |
| GitHub 关联 | repository | 是否有仓库 | 10% |

#### 2.4.2 NPM 健康度评分算法

```rust
fn calculate_npm_health(package: &NpmPackage) -> HealthScore {
    let mut score = 100.0;

    // 下载量评分（30%）
    // 月下载 > 1000万 = 100分，> 100万 = 80分，> 10万 = 60分
    let download_score = match package.monthly_downloads {
        d if d > 10_000_000 => 100.0,
        d if d > 1_000_000 => 80.0,
        d if d > 100_000 => 60.0,
        d if d > 10_000 => 40.0,
        _ => 20.0,
    };
    score += download_score * 0.30;

    // 维护状态评分（20%）
    // 检查最新版本是否落后超过1年
    let maintenance_score = if is_stale_version(&package.version_date) {
        30.0
    } else {
        100.0
    };
    score += maintenance_score * 0.20;

    // 依赖健康评分（15%）
    let dep_score = calculate_dependency_health(&package.dependencies);
    score += dep_score * 0.15;

    // 维护者评分（15%）
    let maintainer_score = match package.maintainers.len() {
        0 => 0.0,
        1 => 50.0,
        2..=5 => 80.0,
        _ => 100.0,
    };
    score += maintainer_score * 0.15;

    // 许可证评分（10%）
    let license_score = match &package.license[..] {
        "MIT" | "Apache-2.0" | "BSD-2-Clause" | "BSD-3-Clause" | "ISC" => 100.0,
        "GPL-3.0" | "LGPL-3.0" | "MPL-2.0" => 80.0,
        "Proprietary" | "UNLICENSED" => 0.0,
        _ => 60.0,
    };
    score += license_score * 0.10;

    // GitHub 关联评分（10%）
    let github_score = if package.repository.is_some() { 100.0 } else { 30.0 };
    score += github_score * 0.10;

    HealthScore { total: score, breakdown: (...) }
}
```

| 指标 | 字段 | 说明 | 评分权重 |

| 发布活跃度 | releases | 版本发布频率 | 25% |
| Python 兼容性 | requires_python | 支持版本范围 | 20% |

#### 3.4.2 PyPI 健康度评分算法

```rust
fn calculate_pypi_health(package: &PyPiPackage) -> HealthScore {
    let mut score = 100.0;

    // 发布活跃度评分（25%）
    // 最近6个月有发布 = 100分，超过1年 = 50分
    let release_score = calculate_release_activity(&package.releases);
    score += release_score * 0.25;

    // Python 兼容性评分（20%）
    let python_score = calculate_python_compatibility(&package.requires_python);
    score += python_score * 0.20;

    // 分类完善度评分（15%）
    let classifier_score = package.classifiers.len() as f32 * 5.0; // 每多一个分类+5分
    let classifier_score = classifier_score.min(100.0);
    score += classifier_score * 0.15;

    // 文档完整性评分（15%）
    let docs_score = if package.info.docs_url.is_some() {
        100.0
    } else if package.info.home_page.is_some() {
        60.0
    } else {
        20.0
    };
    score += docs_score * 0.15;

    // 许可证评分（15%）
    let license_score = analyze_license(&package.info.license);
    score += license_score * 0.15;

    // 维护状态评分（10%）
    let maintenance_score = if package.info.yanked {
        0.0 // 被撤回 = 0分
    } else {
        100.0
    };
    score += maintenance_score * 0.10;

    HealthScore { total: score, breakdown: (...) }
}
```

### 7.2 适配器实现

```rust
pub struct NpmAdapter;
pub struct PyPiAdapter;
pub struct CratesAdapter;
pub struct DockerHubAdapter;

impl PlatformAdapter for NpmAdapter {
    fn platform_id(&self) -> &str { "npm" }
    fn platform_name(&self) -> &str { "NPM" }
    fn platform(&self) -> Platform { Platform::Npm }
    
    fn detect_package_url(&self, input: &str) -> Option<String> {
        if input.contains("npmjs.com") || input.contains("npmjs.org") {
            Some(input.to_string())
        } else if !input.contains("/") {
            // 纯包名，生成 URL
            Some(format!("https://www.npmjs.com/package/{}", input))
        } else {
            None
        }
    }
    
    async fn fetch_package(&self, url: &str) -> Result<PlatformPackage, FetchError> {
        // 提取包名
        let name = extract_npm_package_name(url)?;
        
        // 调用 API
        let api_url = format!("https://registry.npmjs.org/{}", name);
        let response = reqwest::get(&api_url).await?;
        let data: Value = response.json().await?;
        
        // 解析为统一结构
        parse_npm_response(data)
    }
    
    fn calculate_health(&self, package: &PlatformPackage) -> HealthScore {
        calculate_npm_health(package)
    }
}
```
