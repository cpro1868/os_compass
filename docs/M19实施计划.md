## 1 平台扩展（M19.1）

### 1.2 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                     项目导入流程                              │
│  用户输入 URL/包名 → URL 识别 → 平台适配器 → API 获取 → 评分  │
└─────────────────────────────────────────────────────────────┘
                            │
┌─────────────────────────────────────────────────────────────┐
│                    平台适配器层                               │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐                     │
│  │NPM      │  │PyPI     │  │Crates.io│                     │
│  │Adapter  │  │Adapter  │  │Adapter  │                     │
│  └─────────┘  └─────────┘  └─────────┘                     │
└─────────────────────────────────────────────────────────────┘
```

## 3 定时采集功能（M19.3）

### 3.1 功能概述

情报雷达定时自动采集，有新内容时通知用户。

### 3.2 采集模式

| 模式 | 说明 | 示例 |
|------|------|------|
| 间隔模式 | 固定时间间隔 | 5分钟/15分钟/30分钟/1小时/2小时/6小时/12小时/24小时 |
| 自定义模式 | 秒/分/时自定义 | 每30秒、每5分钟、每1小时 |

### 3.3 原型设计

**文件**：`design-system/public/radar-inbox.html`

**顶部栏布局**：
```
[Logo] 情报雷达 | 时间筛选 | 清空 | ⏰ 自动采集(OFF) | ⚙️ | 立即扫描 | 隐藏信息源
```

**定时采集开关**：
- 显示 OFF/ON 状态
- 点击开关直接切换
- 开启后显示当前间隔（如"每15分钟"）
- 旁边设置按钮打开配置弹窗

**配置弹窗**：
- 采集模式：间隔模式 / 自定义模式
  - 间隔模式：下拉选择固定间隔
  - 自定义模式：秒/分/时三级选择 + 数值输入
- 通知设置：启用通知 / 系统通知 / 雷达图标徽章
- 运行状态：当前状态 + 下次采集时间
