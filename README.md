# OS-Compass（开源罗盘）

一款基于"本地优先 (Local-First)"理念设计的跨平台桌面端开源项目全生命周期管理与决策系统。

## 项目定位

OS-Compass 不是简单的书签管理器，而是为开发者量身定制的 **"AI 开源资产智能管家"**：

- 通过大语言模型自动分析、翻译、归纳开源项目
- 通过多层级分类树建立个人技术知识图谱
- 通过本地工作区联动实现一键克隆、IDE 直达
- 通过插件化架构预留未来扩展能力

## 核心痛点

1. **收藏即吃灰**：Star/书签缺乏分类和状态追踪
2. **上手成本高**：外文 README、复杂依赖阻碍验证
3. **检索效率低**：业务需求难以匹配最合适的开源方案

## 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Tauri 2.0+ |
| 前端 | React 18 + TypeScript 5 + Tailwind CSS 3 |
| 状态管理 | Zustand |
| 后端 | Rust 1.75+ |
| 数据库 | SQLite 3.40+ |
| ORM | sqlx |
